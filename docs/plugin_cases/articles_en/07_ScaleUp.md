# SCALE UP

- Original (KO): https://support.midasuser.com/hc/ko/articles/60728766698777-ScaleUp
- Video: [07_ScaleUp.mp4](../videos/07_ScaleUp.mp4)
- GEN NX API CHALLENGE 2026

---

A plug-in that automatically computes the response-spectrum scale-up factor Cm
required by the seismic design code and automatically generates the corresponding
design load combinations in GEN NX. It automatically pulls the analysis results and
load-case information needed to derive Cm straight from GEN NX, so the entire
workflow — from checking analysis results, through deriving Cm, to generating design
load combinations and outputting a report — runs as one continuous process without
switching between separate result tables or calculation sheets.

## Features

**01. Step-by-step guidance for first-time users**
An intuitive status bar at the top and pulsing highlights on input fields show the
current progress and the next action, so even first-time users can pick up the full
workflow quickly.

**02. Automatic computation of the scale-up factor Cm**
Compares the base shear from the equivalent static analysis and the response
spectrum analysis by direction, and automatically computes the response-spectrum
scale-up factor Cm required by the seismic design code.

**03. Automatic linkage of GEN NX analysis data**
Automatically pulls the analysis results and load-case information needed to derive
Cm directly from GEN NX, so you can compute it conveniently without repeated result
checking or manual data entry.

**04. Generate load combinations and output a report**
Automatically generates the design load combinations that apply the computed Cm in
GEN NX, and provides a report-output feature summarizing the Cm calculation process
and its basis.
