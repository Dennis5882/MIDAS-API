# GenSnap

- Original (KO): https://support.midasuser.com/hc/ko/articles/60728171680281-GenSnap
- Video: [14_GenSnap.mp4](../videos/14_GenSnap.mp4)
- GEN NX API CHALLENGE 2026

---

A single executable (.exe) tool that lets you check off, from a model already
analyzed and open in MIDAS GEN NX, analysis images such as the 3D shape, vibration
mode shapes, and seismic/wind displacement distribution, along with review graphs
such as story drift ratio, story shear, and mass participation ratio, display them
on the program screen, and save them — individually or in a batch — as images
(JPG/PNG), graphs (PNG), and an Excel (xlsx) file of the review graphs.

## Features

**01. Model extraction**
Read-only — it never changes the model — and automatically recognizes the load names
and number of modes from the model.

**02. Turning results into images**
Automates turning analysis results into images and graphs, cutting report-prep time,
with the goal of producing output in the same Excel format already used in practice.

**03. Report review**
Analysis images and review graphs needed for review-committee submissions and
structural review reports can be gathered in a batch with just a few clicks.

**04. Load names**
Automatically recognizes load names and the number of modes, so it can be reused
without reconfiguration even when the model changes.
