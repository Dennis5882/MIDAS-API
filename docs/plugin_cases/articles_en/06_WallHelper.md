# WallHelper

- Original (KO): https://support.midasuser.com/hc/ko/articles/60729121274521-WallHelper
- Video: [06_WallHelper.mp4](../videos/06_WallHelper.mp4)
- GEN NX API CHALLENGE 2026

---

A plug-in that, from a single screen, splits rectangular walls in GEN NX at a
reference length, cleans up and merges them to fit the surrounding node grid, and
automatically corrects them based on their layout direction.

## Features

**01. Wall review**
Because every wall is processed with the same rule, model consistency improves
regardless of who built it, and the model is easy to revise during review and
editing.
