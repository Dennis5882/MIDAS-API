# Vibration Analysis Assistant

- Original (KO): https://support.midasuser.com/hc/ko/articles/60809469562649-VibrationAnalysisAssistant
- Video: [03_VibrationAnalysisAssistant.mp4](../videos/03_VibrationAnalysisAssistant.mp4)
- GEN NX API CHALLENGE 2026

---

Vibration Analysis Assistant is a plug-in that lets you input, review, and apply the
Time History Function, Time History Load Case, and Dynamic Nodal Load data needed to
check pedestrian-induced vibration of slabs or beam members in a MIDAS GEN NX
analysis model — all from a single screen. Graphs and tables let you check load
characteristics directly, and the GEN NX API lets you push the Time History data to
the model quickly.

## Features

**01. Batch input for pedestrian loads**
Brings together the function, analysis case, damping condition, and nodal load
inputs needed for pedestrian-load review, all configurable from one screen.

**02. Real-time review of load functions**
As soon as an input changes, the graph and table for the IABSE pedestrian load time
function update in sync, so you can immediately check load magnitude, duration, and
time step.

**03. Automatic application of GEN NX API input data**
Creates, edits, and deletes input data such as the Time History Function, Time
History Load Case, and Dynamic Nodal Load through the API, applying them to the GEN
NX model right away.

**04. Fewer repetitive steps and input errors**
Cuts down on the manual work of moving between scattered feature windows, letting
you create vibration-review conditions to a consistent standard, quickly and
reliably.
