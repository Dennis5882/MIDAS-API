# AutoWallRebarData

- Original (KO): https://support.midasuser.com/hc/ko/articles/60726629959961-AutoWallRebarData
- Video: [18_AutoWallRebarData.mp4](../videos/18_AutoWallRebarData.mp4)
- GEN NX API CHALLENGE 2026

---

A plug-in that lets you select GEN NX wall rebar data (Modify Wall Rebar Data) by
Wall Mark or by thickness, then enter the vertical, horizontal, end-confinement, and
boundary-element rebar together with cover and thickness for each story range in one
step, and export the entered rebar arrangement as a PDF, organized in a table by
Wall Mark.

## Features

**01. Story repetition**
Automates the repetitive manual work of applying rebar arrangements across story
ranges in a batch.

**02. Wall review**
Also automatically organizes the model's wall rebar data into a table by mark (story
range, rebar, cover, thickness) and exports it as a PDF — output you can use
directly for design review and document preparation.
