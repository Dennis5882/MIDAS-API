# Scaffold-Model

- Original (KO): https://support.midasuser.com/hc/ko/articles/60728663462809-ScaffoldModel
- Video: [08_ScaffoldModel.mp4](../videos/08_ScaffoldModel.mp4)
- GEN NX API CHALLENGE 2026

---

This plug-in is a practical tool that automates the main steps of working with
single-pole and double-pole scaffolding in MIDAS GEN NX — from building the model,
through applying loads, running the structural analysis and steel code check, saving
result images, and producing the scaffold structural review report.

## Features

**01. Automatic scaffold model generation**
Automatically generates single-pole or double-pole scaffold models based on the
entered conditions.

**02. Automatic application of loads and analysis conditions**
Automatically applies wind load, noise-barrier and debris-net/working-platform
loads, boundary conditions, and load combinations.

**03. Structural analysis and steel code check**
Runs the structural analysis and steel code check in sequence, and shows the review
result as OK or NG.

**04. Save analysis result images and produce the review report**
Automatically saves analysis result images and generates a scaffold structural
review report incorporating the input data and result images.
