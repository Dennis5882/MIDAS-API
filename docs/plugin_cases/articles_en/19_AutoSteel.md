# AutoSteel

- Original (KO): https://support.midasuser.com/hc/ko/articles/60726583359129-AutoSteel
- Video: [19_AutoSteel.mp4](../videos/19_AutoSteel.mp4)
- GEN NX API CHALLENGE 2026

---

A tool that optimizes the steel sections of a MIDAS GEN NX model.

## Features

**01. Reduced material quantity**
Finds members with spare capacity in GEN NX's design-check results and steps them
down, one size at a time, on the standard H-beam size ladder, reducing the total
steel quantity.

**02. Automatic member-size decision**
The plug-in automatically decides the member size closest to a target design ratio
specified by the user.
