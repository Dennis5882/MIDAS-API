# EasyApartmentBuilder

- Original (KO): https://support.midasuser.com/hc/ko/articles/60728140059161-EasyApartmentBuilder
- Video: [15_EasyApartmentBuilder.mp4](../videos/15_EasyApartmentBuilder.mp4)
- GEN NX API CHALLENGE 2026

---

A plug-in that enables easy, fast apartment analysis modeling from a structural-plan
DXF, through automated Wall Mark/ID assignment.

## Features

**01. Automatic Wall Mark generation**
Automatically generates Wall Marks to name walls, which can then be changed to suit
the user's preference.

**02. Automatic Wall ID assignment**
Automatically assigns Wall IDs based on the Wall Marks, to satisfy GEN NX's wall
design logic (design per Wall ID).

**03. Reference-story support**
Multiple stories' DXF files can be considered as needed, and a reference story can
be designated so the same Wall Mark/ID assignment is applied identically to other
stories.

**04. Convenience features**
The plug-in lets you check the Material, Properties, and Thickness that will be used
before modeling, and handles beam and column elements together as well, making
complex modeling easy.
