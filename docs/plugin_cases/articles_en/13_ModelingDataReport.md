# ModelingDataReport

- Original (KO): https://support.midasuser.com/hc/ko/articles/60728254615449-ModelingDataReport
- Video: [13_ModelingDataReport.mp4](../videos/13_ModelingDataReport.mp4)
- GEN NX API CHALLENGE 2026

---

A plug-in that collects the full set of declared data (structural system / stories /
materials / sections / boundary conditions / loads / analysis options) from the
model currently open in GEN NX via the MIDAS API, and automatically generates a
"modeling review report" (PDF, Excel) ready to attach directly as an appendix to the
structural calculation document.

## Features

**01. Shorter model-review time**
A full review of the model built in GEN NX cuts down the time both senior and
junior engineers spend checking the modeling.

**02. Prevents omissions**
Prevents easy-to-miss omissions in items such as self-weight, boundary conditions,
and stiffness factors that are scattered across menus.

**03. Less effort writing review documents**
Story drift and irregularity checks are compiled automatically as well, reducing the
effort of preparing seismic-related review documents.
