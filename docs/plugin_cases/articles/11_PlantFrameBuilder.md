Plant Frame Builder
Bay 간격·층고 등 입력값만으로 2열 다층 Pipe Rack의 초기 구조해석용 철골 Frame 모델(Node/Column/Beam/Brace/Support)을
          자동 생성하는 GEN NX API 플러그인입니다.
FEATURES
주요 기능
01
파라미터 기반 초고속 자동 모델링
(반복 입력 제거·실무 유연성)
복잡한 수작업 없이 파라미터(Bay 간격, 층고 등) 입력만으로 Pipe
                    Rack 골조를 단숨에 완성합니다. 기존 모델의 재료(Material)와
                    단면(Section)을 불러오는 것은 물론, UI 내에서 신규 생성·배정까지
                    즉시 가능하여 빈 모델에서도 바로 시작할 수 있습니다. 형상부터 지점 조건까지
                    일괄 처리되어 반복적인 모델링 작업시간을 효과적으로 단축해 줍니다.
02
실시간 3D 미리보기 및 완벽한 사전 검증
(휴먼 에러 차단)
파라미터 변경 시 실시간 3D 미리보기가 갱신되어 형상을 직관적으로 확인할
                    수 있습니다. GEN NX 모델 반영 직전에는 예상 부재 수량과 부여되리
                    ID 범위, 기존 모델과의 충돌 여부를 검증합니다. 검증을 통과한 안전한
                    상태에서만 모델이 생성되므로 휴먼 에러를 차단합니다.
