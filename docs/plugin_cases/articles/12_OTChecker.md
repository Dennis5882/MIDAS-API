OT CHECKER
GEN NX 해석결과와 사용자가 입력한 설계조건을 바탕으로 풍하중 및 지진하중에 대한 구조물의 전도 안정성을
          검토하는 플러그인입니다. 전도 검토에 필요한 고정하중 지점반력과 전도모멘트를 GEN NX에서 자동으로 불러오며,
          별도의 결과표나 계산 시트를 오갈 필요 없이 해석결과 확인부터 전도 안정성 검토, 지배 조건 판정과 보고서 출력까지
          하나의 연속된 작업 흐름으로 수행할 수 있습니다.
FEATURES
주요 기능
01
처음 사용자를 위한 단계별 안내
상단 상태 안내바와 입력 항목의 맥동 강조 효과를 통해 현재 진행 상태와
                    다음 작업을 직관적으로 안내하여, 처음 사용하는 사용자도 전체 작업 흐름을
                    쉽게 익힐 수 있습니다.
02
GEN NX 결과 자동 연동
GEN NX에서 고정하중 지점반력과 풍·지진 하중케이스의 기초층 전도모멘트를
                    자동으로 불러오고, 실제 회전팔 거리와 모델 외 기초 및 벽체 자중을 반영하여
                    저항모멘트를 산정합니다.
03
전도 안정성·지배 조건 판정
강도설계법 또는 허용응력설계법에 따른 KDS 하중조합을 구성하고, 풍하중과
                    지진하중의 전도모멘트·저항모멘트 및 안전율을 일괄 비교하여 지배 조건을 판정합니다.
04
산정 근거 보고서 출력
입력 조건, GEN NX 해석결과, 전도 안정성 검토 결과와 상세 산정 근거를
                    정리한 보고서 출력 기능을 제공합니다.
