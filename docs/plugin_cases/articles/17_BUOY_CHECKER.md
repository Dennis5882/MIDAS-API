BUOY CHECKER
GEN NX 해석결과와 사용자가 입력한 설계조건을 바탕으로 구조물의 완공 및 시공단계별 부상 안전성을 검토하는
          플러그인입니다. 검토에 필요한 해석결과를 GEN NX에서 자동으로 불러오며, 별도의 결과표나 계산 시트를 오갈
          필요 없이 단계별 안전율 검토부터 관리수위 산정, 보고서 출력까지 하나의 연속된 작업 흐름으로 수행할 수 있습니다.
FEATURES
주요 기능
01
처음 사용자를 위한 단계별 안내
상단 상태 안내바와 입력 항목의 맥동 강조 효과를 통해 현재 진행 상태와
                    다음 작업을 직관적으로 안내하여, 처음 사용하는 사용자도 전체 작업 흐름을
                    쉽게 익힐 수 있습니다.
02
GEN NX 결과 자동 연동·교차검증
GEN NX에서 Story별 고정하중 축력과 기초 지점반력을 자동으로 불러오고,
                    두 해석결과를 교차검증하여 데이터의 누락과 불일치 여부를 확인합니다.
03
단계별 부상 안전성·관리수위 산정
완공 상태와 시공단계별 부력·저항력 및 부상 안전율을 자동으로 계산하고,
                    목표 안전율을 만족하기 위한 단계별 관리수위를 역산합니다.
04
산정 근거 보고서 출력
입력 조건, 교차검증 결과, 단계별 부상 안전율과 관리수위 산정 근거를 정리한
                    보고서 출력 기능을 제공합니다.
