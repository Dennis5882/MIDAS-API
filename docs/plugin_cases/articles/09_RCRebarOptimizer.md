RCRebarOptimizer
MIDAS GEN NX의 RC 설계 API(DCRM·CD/BD-ANAL·설계결과표)를 활용해, RC 기둥·보의
          주철근을 후보 규격으로 자동 스윕 설계하여 검토비(CHK)를 만족하는 부재별 최소 강재 배근을 산출하고, 같은
          단면(기둥마크·보마크)을 하나의 표준 배근으로 통일하는 플러그인입니다.
FEATURES
주요 기능
01
결과 설계
MIDAS GEN NX의 RC 설계 API(DCRM·CD/BD-ANAL·설계결과표)를
                    활용해, RC 기둥·보의 주철근을 후보 규격으로 자동 스윕 설계.
02
부재 검토
검토비(CHK)를 만족하는 부재별 최소 강재 배근을 산출하고, 같은 단면(기둥마크·보마크)을
                    하나의 표준 배근으로 통일하는 플러그인입니다.
03
부재 설계
모든 표준 배근은 GEN NX 재설계로 검토비를 재검증하므로 안전성을 보장하며,
                    지배요인 진단으로 어느 부재를 더 줄일 수 있는지까지 제시합니다.
04
결과 검토
배근표·비교 결과를 즉시 PDF로 산출해 설계·적산·검토 문서 작성 시간을 크게 단축합니다.
