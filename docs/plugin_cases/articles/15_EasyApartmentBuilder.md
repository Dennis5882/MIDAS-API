EasyApartmentBuilder
구조평면도 기반 .dxf를 바탕으로 Wall Mark/ID 자동화를 통해 쉽고 빠른 아파트 해석모델링을 구현하는

FEATURES
주요 기능
01
Wall Mark 자동생성
Wall Mark 자동 생성을 통해 벽체의 이름을 정의하고 사용자의 편의에 따라 변경가능합니다.
02
Wall ID 자동할당
Wall Mark에 따라 GEN NX의 벽체설계 로직(Wall ID별 설계)을
                    만족하기 위해 Wall ID를 자동으로 할당할 수 있습니다.
03
기준층 고려가능
사용자의 필요에 따라 여러 층의 dxf를 고려할 수 있으며 기준층을 지정하여
                    Wall Mark/ID를 다른 층에 동일하게 할당할 수 있습니다.
04
사용자 편의기능
플러그인 내에서 모델링이 어떻게 구현될지 Material, Properties,
                    Thickness를 확인할 수 있으며 보와 기둥요소도 한번에 고려하여 복잡한
                    모델링을 쉽게 구현할 수 있습니다.
