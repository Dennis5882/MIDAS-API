SolarStructureModeling
MIDAS GEN NX에서 태양광 구조물 형식(CASE 1~4)을 선택하고 치수·재료·단면을 입력하면 절점,보
          요소, 경계조건을 GEN NX 모델에 자동 생성하는 플러그인입니다.
FEATURES
주요 기능
01
모델 입력
치수·재료·단면을 입력하면 절점,보 요소, 경계조건을 GEN NX 모델에 자동 생성하는 플러그인입니다.
02
모델 계산
설치 형식과 주요 치수만 입력하면 기둥·지붕보·브레이스·퍼린 등 모든 구성
                    요소의 절점과 요소가 자동으로 계산·생성되어 구조 모델 구축 시간을 대폭
                    단축합니다.
03
부재 계산
수작업 모델링 대비 절점 번호 계산, 부재 좌표 결정, 경계조건 입력 등의
                    반복 작업이 사라져 구조 모델 생성 시간을 크게 단축할 수 있습니다.
04
하중 계산
중력하중(고정·적재·적설)과 KDS 기반 풍하중이 자동 계산·배정되므로 하중
                    입력 오류를 줄이고 설계 기준 적합성을 확보합니다.
