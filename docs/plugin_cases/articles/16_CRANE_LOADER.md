Crane Loader
크레인 제원을 바탕으로 차륜반력과 주행보 지지기둥의 최대 포락반력을 자동으로 산정하는 플러그인입니다. 버튼 한
          번으로 크레인의 연직·수평하중에 필요한 하중 케이스를 생성하고, 계산된 절점하중을 GEN NX 모델에 일괄 입력할
          수 있습니다. 별도의 계산 도구와 GEN NX를 오갈 필요 없이 하중 산정부터 모델 입력, 적용 근거 확인과
          구조계산 보고서 작성까지 하나의 연속된 작업 흐름으로 완료할 수 있습니다.
FEATURES
주요 기능
01
처음 사용자를 위한 단계별 안내
상단 상태 안내바와 입력 항목의 맥동 강조 효과를 통해 현재 진행 상태와
                    다음 작업을 직관적으로 안내하여, 처음 사용하는 사용자도 전체 작업 흐름을
                    쉽게 익힐 수 있습니다.
02
복수 크레인 최대 포락반력
복수 크레인의 동시 운용 조건을 반영하여 각 크레인의 차륜반력을 계산하고,
                    영향선 해석을 통해 주행보 지지기둥별 최대 포락반력을 자동으로 산정합니다.
03
하중케이스·절점하중 일괄 입력
크레인의 연직·수평하중에 필요한 하중케이스를 자동으로 생성하고, GEN NX
                    모델의 선택 절점에 계산된 절점하중을 하중케이스별로 일괄 입력합니다.
04
산정 근거 보고서 출력
크레인 제원에 따른 차륜반력과 작용하중의 산정 근거를 정리한 보고서 출력 기능을 제공합니다.
