WALL STACKER
구조도면을 활용하여 벽체와 외곽 인방보를 자동으로 모델링하는 플러그인입니다. 벽체 교차부를 자동으로 분할하고,
          도면의 미세한 좌표 차이로 생성되는 근접 절점을 자동으로 정렬·통합하여 요소 간 단절과 불필요한 절점 생성을
          방지한 정확한 해석모델을 신속하게 생성합니다.
FEATURES
주요 기능
01
처음 사용자를 위한 단계별 안내
상단 상태 안내바와 입력 항목의 맥동 강조 효과를 통해 현재 진행 상태와
                    다음 작업을 직관적으로 안내하여, 처음 사용하는 사용자도 전체 작업 흐름을
                    쉽게 익힐 수 있습니다.
02
층별 DXF 벽체 추출·분석
층별 DXF 도면의 중심선과 벽체 정보를 자동으로 추출·분석하여 모델링 대상을 구성합니다.
03
벽체·인방보 자동 모델링
분석된 도면을 기반으로 층별 벽체와 개구부 인방보를 자동으로 모델링합니다.
04
교차 지점 자동 분할
벽체 교차 지점을 자동으로 인식하고 요소를 분할하여, 절점이 공유되는 연결성
                    높은 해석모델을 생성합니다.
05
근접 절점 자동 통합
도면의 미세한 좌표 차이로 동일 접합부에 여러 절점이 생성되는 것을 방지하고,
                    설정한 보정범위 내의 근접 절점을 자동으로 정렬·병합합니다.
