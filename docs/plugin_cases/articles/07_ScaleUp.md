SCALE UP
내진설계기준에 따라 응답스펙트럼해석의 보정계수 Cm을 자동으로 계산하고, 설계용 하중조합을 GEN NX에 자동으로
          생성하는 플러그인입니다. Cm 산정에 필요한 해석결과와 하중케이스 정보를 GEN NX에서 자동으로 불러오며,
          별도의 결과표나 계산 시트를 오갈 필요 없이 해석결과 확인부터 Cm 산정, 설계용 하중조합 생성과 보고서 출력까지
          하나의 연속된 작업 흐름으로 수행할 수 있습니다.
FEATURES
주요 기능
01
처음 사용자를 위한 단계별 안내
상단 상태 안내바와 입력 항목의 맥동 강조 효과를 통해 현재 진행 상태와
                    다음 작업을 직관적으로 안내하여, 처음 사용하는 사용자도 전체 작업 흐름을
                    쉽게 익힐 수 있습니다.
02
보정계수 Cm 자동 계산
등가정적해석과 응답스펙트럼의 밑면전단력을 방향별로 비교하고, 내진설계기준에
                    따른 응답스펙트럼해석의 보정계수 Cm을 자동으로 계산합니다.
03
GEN NX 해석정보 자동 연동
Cm 산정에 필요한 해석결과와 하중케이스 정보를 GEN NX에서 자동으로
                    불러와 반복적인 결고 확인과 수작업 입력없이 편리하게 계산할 수 있습니다.
04
하중조합 생성·보고서 출력
계산된 Cm을 적용한 설계용 하중조합을 GEN NX에 자동으로 생성하며,
                    Cm 계산 과정과 적용 근거를 정리한 보고서 출력기능을 제공합니다.
