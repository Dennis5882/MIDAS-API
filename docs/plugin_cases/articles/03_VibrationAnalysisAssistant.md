Vibration Analysis Assistant
Vibration Analysis Assistant는 MIDAS GEN NX 해석모델에서 슬래브 또는 보 부재의
          보행하중 진동 검토에 필요한 Time History Function, Time History Load Case,
          Dynamic Nodal Load 입력을 한 화면에서 입력·검토·적용할 수 있도록 지원하는 Plug-in입니다.
          그래프와 표를 통해 하중 특성을 직접 확인하고, GEN NX API를 활용해 Time History 데이터를
          모델에 빠르게 반영할 수 있습니다.
FEATURES
주요 기능
01
보행하중 일괄 입력
보행하중 검토에 필요한 동적하중의 함수, 해석 케이스, 감쇠 조건, 노드
                    하중 입력을 한 화면에서 설정할 수 있도록 구성했습니다.
02
하중 함수 실시간 검토
입력값 변경 즉시, IABSE 보행하중 시간함수의 그래프와 표가 동기화되어
                    하중 크기, 지속시간, 시간 간격을 바로 확인할 수 있습니다.
03
GEN NX API 입력 데이터 자동 적용
Time History Function, Time History Load
                    Case, Dynamic Nodal Load와 같은 입력 데이터를 API로
                    생성·수정·삭제하여 GEN NX 모델에 바로 적용할 수 있습니다.
04
반복 작업 수행 및 입력 오류 감소
흩어져 있는 여러 기능창을 오가며 수작업으로 입력하던 과정을 줄이고, 동일한
                    기준의 진동 검토 조건을 빠르고 일관성 있게 생성할 수 있습니다.
