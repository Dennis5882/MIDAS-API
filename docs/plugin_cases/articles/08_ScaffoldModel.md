Scaffold-Model
본 Plug-in은 MIDAS GEN NX에서 외줄비계 및 쌍줄비계의 모델 생성부터 하중 재하, 구조해석, Steel
          Code Check, 결과 이미지 저장 및 비계 구조검토서 작성까지의 주요 과정을 자동화한 실무형 도구입니다.
FEATURES
주요 기능
01
비계 모델 자동 생성
입력한 조건에 따라 외줄비계 및 쌍줄비계 모델을 자동으로 생성합니다.
02
하중 및 해석 조건 자동 적용
풍하중과 방음벽, 낙하물방지망 및 작업발판 하중, 경계조건 및 하중조합을 자동으로 적용합니다.
03
구조해석 및 Steel Code Check
구조해석과 Steel Code Check를 순차적으로 수행하고, 검토 결과를
                    OK 또는 NG로 확인할 수 있습니다.
04
해석 결과 이미지 저장 및 검토서 작성
해석 결과 이미지를 자동으로 저장하고, 입력 정보와 결과 이미지를 반영한 비계 구조검토서를 생성합니다.
