# WallHelper

- 原文（韓文）：https://support.midasuser.com/hc/ko/articles/60729121274521-WallHelper
- 影片：[06_WallHelper.mp4](../videos/06_WallHelper.mp4)
- GEN NX API CHALLENGE 2026

---

這是一款可在單一畫面中，將 GEN NX 的矩形牆（Wall）依基準長度分割、依周邊節點格線整理合併，
並依配置方向自動修正的外掛程式。

## 主要功能

**01. 牆體檢視**
由於以相同規則處理牆體，可提高不同負責人建立模型的一致性，在檢視、修改階段也能方便地調整模型。
