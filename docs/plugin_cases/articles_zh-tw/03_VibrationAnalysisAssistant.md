Vibration Analysis Assistant 是一款外掛程式，讓使用者能在單一畫面中輸入、檢視並套用
MIDAS GEN NX 分析模型中，板或梁構件人行走載重振動檢核所需的 Time History Function、
Time History Load Case、Dynamic Nodal Load。可透過圖形與表格直接確認載重特性，並利用
GEN NX API 快速將 Time History 資料反映至模型中。

## 主要功能

**01. 人行走載重一次性輸入**
將人行走載重檢核所需的動態載重函數、分析工況、阻尼條件、節點載重輸入，整合於單一畫面中設定。

**02. 載重函數即時檢視**
輸入值一經變更，IABSE 人行走載重時間函數的圖形與表格即同步更新，可立即確認載重大小、
持續時間與時間間隔。

**03. GEN NX API 輸入資料自動套用**
透過 API 建立、修改、刪除 Time History Function、Time History Load Case、
Dynamic Nodal Load 等輸入資料，並直接套用至 GEN NX 模型。

**04. 減少重複作業與輸入錯誤**
減少往返多個分散功能視窗手動輸入的過程，可快速且一致地依相同基準建立振動檢核條件。
