本外掛程式為實務型工具，將 MIDAS GEN NX 中單排、雙排施工架的模型建立、載重加載、結構分析、
Steel Code Check、結果影像儲存到施工架結構檢討書製作等主要流程全面自動化。

## 主要功能

**01. 自動建立施工架模型**
依輸入條件自動建立單排或雙排施工架模型。

**02. 自動套用載重與分析條件**
自動套用風力載重、隔音牆、防墜網及工作台載重、邊界條件與載重組合。

**03. 結構分析與 Steel Code Check**
依序執行結構分析與 Steel Code Check，並可確認檢核結果為 OK 或 NG。

**04. 儲存分析結果影像並產出檢討書**
自動儲存分析結果影像，並產出反映輸入資訊與結果影像的施工架結構檢討書。
