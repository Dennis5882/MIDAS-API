# AutoSteel 기획문서

> 영상(`docs/plugin_cases/videos/19_AutoSteel.mp4`, 30fps, 1920×1080, 약 90초)을 5초 간격으로
> 프레임 캡처(총 18장) 후 프레임별 육안 분석 + 화면 상단 STEP 라벨 자막을 근거로 작성. 원문
> 아티클(`docs/plugin_cases/articles/19_AutoSteel.md`)의 2대 기능 설명과 교차 확인함. 이 영상은
> 실제 GEN NX 화면을 전혀 보여주지 않고 **독립 실행형 데스크톱 앱(AutoSteel.exe)의 UI만으로
> 전체 워크플로우를 설명**하며, 진행 로그에 GEN NX 설계 옵션 필드명(`DEFL_CHK`, `CODE-ANAL`
> 등)이 그대로 노출되어 API 매핑 근거가 확보된다.

## 1. 개요

**AutoSteel**은 MIDAS GEN NX 모델의 강재 단면을 최적화 설계하는 도구다. GEN NX의 설계검토
결과에서 여유가 남는 부재를 찾아 표준 H형강 사다리(size ladder)에서 한 단계씩 내려 강재
총량을 줄이고, 사용자가 지정한 목표 설계비에 가장 가까운 부재 사이즈를 자동으로 결정한다.

## 2. 문제 정의

- 초기 철골 모델링 단계에서는 안전 측으로 넉넉한 단면을 배정하는 경우가 많은데, 설계검토
  결과 여유(강도 여유율)가 큰 부재를 찾아 표준 규격 사다리에서 한 단계씩 낮춰 강재량을
  줄이는 작업은 부재 수가 많을수록 반복적이고 시간이 걸린다.
- 목표 설계비(예: 0.90)에 가장 근접한 사이즈를 수작업으로 하나씩 대입해가며 찾는 것은
  비효율적이다.

## 3. 목표 사용자

- 철골 구조물의 강재 물량을 절감하려는 구조 설계자, 특히 초기 모델링 후 최적화 단계에 있는
  실무자.

## 4. 핵심 컨셉 / 차별점

- **표준 H형강 사다리에서 단계적 경량화**: 임의의 치수를 계산하는 것이 아니라, 실제 유통되는
  표준 H형강 규격 목록("사다리")에서 현재 사이즈보다 한 단계 작은 규격으로 낮추는 방식 — 실제
  발주·조달 가능한 규격만 사용하도록 보장.
- **목표 설계비 기준 자동 수렴**: "목표 설계비 ratio"(예 0.90) 하나만 입력하면, 이 값을
  초과하는(위반) 부재를 자동으로 판정하고 그 기준에 가장 가까운 사이즈로 수렴시킨다.
- **잠금 부재번호로 특정 부재 제외**: 특정 부재 번호(예: 12, 13, 41)를 "잠금"으로 지정하면
  최적화 대상에서 제외(고정) — 특수 부재(예: 브레이스 접합부 인접 부재)를 건드리지 않고
  나머지만 최적화할 수 있음. 비우면 전체 대상.
- **경량화 → 재검토 → 상향(up-sizing) 자동 루프**: 한 번 낮춘 사이즈가 재검토 결과 여유가
  부족(위반)하면 자동으로 한 단계 다시 올리고(상향), 그 상태로 "상향 확정"하여 더 이상
  바꾸지 않는 이력 관리형 알고리즘 — 단순 하향 탐색이 아니라 양방향 탐색.
- **진행 상황을 8가지 상태 태그로 실시간 시각화**: 경량화(내림)/유지/상향(올림)/상향 확정/
  검증 통과/실패·중단/제외 — 부재별로 어떤 상태를 거쳐 최종 사이즈가 결정됐는지 색상 라벨로
  전부 추적 가능.
- **원본 보호를 위한 사본 저장 강제**: 최적화 시작 시 "모델링 변경이 동반됩니다. 사본 저장 뒤
  최적화를 진행하겠습니다"라는 확인창을 반드시 거치고, 원본 파일을 건드리지 않고 `.mgbx` 사본
  파일에 최적화를 진행 — 실수로 원본을 덮어쓰는 사고를 원천 차단.
- **원상복구 버튼**: 최적화 결과가 마음에 들지 않으면 "원상복구" 버튼 하나로 최적화 이전
  상태로 즉시 되돌릴 수 있음.
- **자동검증 한계를 스스로 고지("정직 포인트")**: 처짐(Deflection) 등 이 실행에서 자동
  산출되지 않은 검토 항목("INACTIVE: GEN이 DEFL_CHK+CODE-ANAL 후에도 처짐값(DEFA) 미산출.
  이 실행에서 처짐 안전은 검증되지 않음")을 결과 화면에 명시적으로 경고하고, 최장 관리부재
  (예: 7m)에 대해 "별도 수단으로 반드시 수동 확인할 것"을 요구 — 자동화가 커버하지 못하는
  부분을 숨기지 않고 사용자에게 명확히 알리는 설계 철학이 두드러짐.

## 5. 워크플로우

### Step 1 — 연결

- AutoSteel 실행 → "GEN NX에 모델(사본)을 열고" MAPI-Key를 입력 → [연결] 클릭.
- 연결되면 상태 배지가 "연결됨 · 모델 부재 63 · 단면 2"로 표시(대상 모델의 부재·단면 수 자동
  인식).

### Step 2 — 목표 입력

- 목표 설계비 ratio(예 0.90) 입력 — "이 값을 초과하는 부재는 위반으로 판정합니다(0.5~1.0,
  필수)".
- 잠금 부재번호(쉼표 구분, 선택) — "지정한 부재번호는 사이징에서 제외(고정)합니다. 비우면
  전체 대상".

### Step 3 — 실행·안전

- "최적화 시작" 클릭 → "모델링 변경이 동반됩니다. 사본 저장 뒤 최적화를 진행하겠습니다" 확인
  모달 → 확인 클릭.
- 원본을 지키기 위해 사본(.mgbx, 예 `AutoSteel_사본_20260731.mgbx`)을 별도 경로에 먼저
  저장한 뒤 진행.

### Step 4 — 진행 상황(반복 재해석)

- 진행 로그에 부재별 판정이 순차 출력됨. 예시:
  - "세장비 보수 검토 — 인장 전용 부재 36본: 압축 전환 가능성에 대해 세장비를 보수적으로
    검토합니다"
  - "경량화 — H 400x200x8/13 (36본): 강도 여유 16% → H396x199x7/11(으)로 경량화(본당
    -65.7kg 절감)"
  - "경량화 — H 400x400x13/21 (27본): 강도 여유 74% → H200x200x8/12(으)로 경량화(본당
    -478.7kg 절감)"
  - "상향 — H 400x200x8/13 (36본): 재검토 결과 여유 부족 → H400x200x8/13(으)로 상향"
  - "상향 확정 — H 400x200x8/13 (36본): 상향 확정 — 이후 변경하지 않습니다"
  - "상향 — H 400x400x13/21 (27본): 재검토 결과 여유 부족 → H250x250x9/14(으)로 상향"
  - "상향 확정 — H 400x400x13/21 (27본): 상향 확정 — 이후 변경하지 않습니다"
  - "검증 통과 — 최종 검증 통과: 강도·세장비 이상 없음(처짐은 별도 확인)"
- 즉 최초 경량화(400x200x8/13 → 396x199x7/11 등)가 재검토에서 여유 부족으로 판정되면
  자동으로 한 단계 상향(396x199x7/11 → 400x200x8/13으로 원복 또는 250x250x9/14로 재조정)
  하고, 그 값으로 확정하는 반복 재해석 루프가 여러 번(관찰된 사례로 최소 2회 이상) 실행됨.

### Step 5 — 결과

- 최종 결과 카드: 총중량(최적화 대상) 34,397.1 → 23,834.7kg, **절감률 30.7%**(전체 모델
  기준 절감률 30.5%, 비대상 부재 포함).
- 부재별 최적화 이전/이후 단면 비교표(부재명·지수·재질): 예 `H 400x200x8/13` →
  `H-400X200X8X13`(변경 없음, 상향 확정 결과), `H 400x400x13/21` → `H-250X250X9X14`(경량화
  확정 결과).
- "남은 위반: 없음(강도·세장비 만족)".
- **확인이 필요한 항목**(자동검증 한계 고지):
  1. "처짐 검토: INACTIVE — GEN이 DEFL_CHK+CODE-ANAL 후에도 DEFA 미산출. 이 실행에서 처짐
     안전은 검증되지 않음. 최장 관리부재 7m — 처짐 위험 상존, 별도 수단으로 반드시 수동
     확인할 것"
  2. "설계검토 결과가 없는 부재: 0본 — 자동 경량화 대상이 아니므로 원단면 유지, 수동 확인이
     필요합니다"
  3. "인장 전용 부재 보수 검토: 36본 — 압축 전환 가능성에 대해 세장비를 보수적으로 판정했
     습니다"
- "부재별 이전/이후 단면 표 + [계산서 저장(xlsx)]으로 내보내기" 가능.
- 결과가 마음에 안 들면 "원상복구" 버튼으로 최적화 이전 상태로 즉시 복귀 가능.

## 6. 연계 JSON API 엔드포인트

진행 로그에 GEN NX 강재 설계 옵션의 실제 필드명(`DEFL_CHK`)과 실행 단계명(`CODE-ANAL`)이
그대로 노출되어 있어, #8(ScaffoldModel)에서 확인한 KDS 41 30:2022 강재 설계 API 계열과
동일한 엔드포인트를 사용함을 강하게 시사한다:

| 기능 | 추정 API | 문서 위치 |
| --- | --- | --- |
| 설계 코드 옵션(처짐 검토 포함 여부 `DEFL_CHK`) | `POST DESIGN/STEEL/KDS-41-30-2022/DCO` | [`25_Design_Steel_KDS41302022.md#1-designsteelkds-41-30-2022dco--design-code-option-설계-코드-옵션`](../../manual/25_Design_Steel_KDS41302022.md#1-designsteelkds-41-30-2022dco--design-code-option-설계-코드-옵션) |
| 강재 코드 검토 수행(재검토 반복) | `POST DESIGN/STEEL/KDS-41-30-2022/CODE-ANAL` | [`25_Design_Steel_KDS41302022.md#23-designsteelkds-41-30-2022code-anal--steel-code-check-perform-강재-코드-검토-수행`](../../manual/25_Design_Steel_KDS41302022.md#23-designsteelkds-41-30-2022code-anal--steel-code-check-perform-강재-코드-검토-수행) |
| 검토 결과(여유율, 위반 여부) 조회 | `POST DESIGN/STEEL/KDS-41-30-2022/CODE-TABLE` | [`25_Design_Steel_KDS41302022.md#24-designsteelkds-41-30-2022code-table--steel-code-check-table-강재-코드-검토-표`](../../manual/25_Design_Steel_KDS41302022.md#24-designsteelkds-41-30-2022code-table--steel-code-check-table-강재-코드-검토-표) |
| 단면 변경(경량화/상향) | `PUT /db/SECT` | [`04_DB_Properties.md#12-dbsect`](../../manual/04_DB_Properties.md#12-dbsect) |

- `DEFL_CHK`는 `docs/manual/25_Design_Steel_KDS41302022.md` §1 `DCO`(Design Code Option)의
  Specifications 표에 "보/기둥 처짐 검토, Key: `DEFL_CHK`, Boolean, 기본값 true"로 정확히
  문서화되어 있어, 로그의 "GEN이 DEFL_CHK+CODE-ANAL 후에도 DEFA 미산출"이라는 문구가 실제
  API 필드명을 그대로 인용한 것임을 확인했다 — 이 세션에서 필드명까지 정확히 대조된 사례.
- ⚠️ `DEFA`(처짐 결과값으로 추정되는 필드명)는 `docs/manual`에서 정확히 일치하는 문서를
  찾지 못했다 — Steel Code Check Table(`CODE-TABLE`) 응답의 세부 컬럼 중 하나로 추정되나
  확인되지 않았다.
- 경량화·상향 판정 알고리즘(표준 사다리에서 몇 단계 이동할지, 언제 상향을 확정할지) 자체는
  API가 제공하는 결과가 아니라 Plug-in이 `CODE-TABLE` 응답(여유율)을 바탕으로 직접 구현한
  탐색 로직으로 보인다.

## 7. 입력 데이터 규격

- **목표 설계비 ratio**: 0.5~1.0 범위, 필수.
- **잠금 부재번호**: 쉼표로 구분한 부재 번호 목록(선택, 비우면 전체 대상).
- **선행 조건**: GEN NX 모델에 강재 설계검토(KDS 41 30:2022)가 이미 수행되어 있어야 함(연결
  시 "모델 부재 63·단면 2"로 자동 인식).

## 8. 출력 / 생성 결과

- GEN NX 모델(사본 `.mgbx`)에 반영된 최적화 후 단면(`/db/SECT`).
- 총중량 절감 요약(최적화 대상/전체 모델 기준), 부재별 이전/이후 단면 비교표.
- 계산서(xlsx) 내보내기.

## 9. 제약사항 및 한계

- **처짐(Deflection) 검토는 이 실행에서 자동 검증되지 않는다** — Plug-in 스스로 명시한
  한계로, 최적화된 단면이 강도·세장비는 만족하더라도 처짐 기준을 만족하는지는 별도로 수동
  확인해야 한다. 특히 장경간 부재(예 7m 이상)에서 이 위험이 특히 강조됨.
- 인장 전용 부재는 압축 전환 가능성을 고려해 세장비를 "보수적으로" 판정한다고 명시되어 있어,
  이 부재들의 최적화 폭은 다른 부재보다 제한적일 수 있다.
- 설계검토 결과 자체가 없는 부재는 자동 경량화 대상에서 제외되고 원단면이 유지되며, 이 경우도
  사용자가 별도로 수동 확인해야 한다.
- 표준 H형강 "사다리" 목록의 구체적인 규격 범위(어떤 카탈로그 기준인지)는 화면에서 명시적으로
  확인되지 않았다(⚠️ 미확인).

## 10. 화면 인벤토리

| 시점(초) | 화면 내용 |
| --- | --- |
| 0–5 | 인트로(암전) |
| 5–15 | STEP 1 연결 — MAPI-Key 입력, 연결 완료 상태 표시 |
| 15–25 | STEP 2 목표 입력 — 목표 설계비 ratio, 잠금 부재번호 |
| 25–40 | STEP 3 실행·안전 — 모델링 변경 동반 확인, 사본 저장 |
| 40–55 | STEP 4 진행 상황 — 세장비 보수 검토, 경량화 로그(400x200x8/13, 400x400x13/21) |
| 55–65 | STEP 4 반복 재해석 — 상향/상향 확정 로그 |
| 65–80 | 결과 — 총중량 34,397.1→23,834.7kg(30.7% 절감), 부재별 비교표, 계산서 저장(xlsx) |
| 80–85 | 정직 포인트 — 확인 필요 항목(처짐 미검증 등) 강조 |
