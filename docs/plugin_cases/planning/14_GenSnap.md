# GenSnap 기획문서

> 영상(`docs/plugin_cases/videos/14_GenSnap.mp4`, 24fps, 1280×720, 약 132초)을 6초 간격으로
> 프레임 캡처(총 23장) 후 프레임별 육안 분석 + 슬라이드 자막을 근거로 작성. 원문
> 아티클(`docs/plugin_cases/articles/14_GenSnap.md`)의 4대 기능 설명과 교차 확인함. 이 세션의
> 다른 사례들과 달리 GEN NX 화면 녹화가 아니라 **처음부터 끝까지 슬라이드/UI 스크린샷으로만
> 구성된 사용법 설명 영상**이며, Plug-in 자체도 GEN NX에 내장되지 않고 "GEN 중계서버 인증 키
> (MAPI-Key)"로 외부에서 접속하는 **단일 실행파일(.exe)** 형태다.

## 1. 개요

**GenSnap**은 MIDAS GEN NX에 열린 해석완료 모델에서 3D 형상·진동 모드형상·지진/풍 변위 분포도
등 해석 이미지와 층간변위비·층전단력·질량참여율 등 검토 그래프를 체크박스로 골라 화면에 표시하고,
이미지(JPG/PNG)·그래프(PNG)와 검토 그래프의 엑셀(xlsx)로 개별/일괄 저장하는 독립 실행형(exe)
Plug-in이다.

## 2. 문제 정의

- 심의계획서·구조검토 보고서에 들어가는 해석 이미지(3D 형상, 모드형상, 변위 분포도)와 검토
  그래프(층간변위비, 층전단력 등)를 GEN NX에서 하나씩 캡처·정리하는 작업은 반복적이고 시간이
  오래 걸린다.
- 실무에서 쓰던 엑셀 양식(표+차트)에 결과를 다시 옮겨 담는 별도 작업이 필요하다.
- 모델마다 하중 이름(RX, RY, WX, WY 등)과 모드 수가 달라, 매번 어떤 항목을 뽑아야 할지 설정을
  다시 해야 하는 번거로움이 있다.

## 3. 목표 사용자

- 심의계획서·구조검토 보고서에 첨부할 해석 이미지·그래프를 반복적으로 뽑아야 하는 구조
  엔지니어.
- 여러 프로젝트를 오가며 동일한 형식의 산출물(이미지·그래프·엑셀)이 필요한 실무자.

## 4. 핵심 컨셉 / 차별점

- **모델 변경 없는 조회 전용(read-only)**: "모델을 변경하지 않는 조회 전용으로, 하중 이름과
  모드 수를 모델에서 자동 인식한다"— 쓰기 작업이 전혀 없어 실수로 모델을 훼손할 위험이 구조적
  으로 차단됨.
- **하중 이름·모드 수 자동 인식**: GEN 연결 시 "지진(응답스펙트럼) 하중 2개(RX·RY), 풍하중
  2개(WX·WY), 진동 모드 15개"처럼 모델에 정의된 하중케이스명과 모드 수를 자동으로 읽어와, 모델이
  바뀌어도 별도 설정 없이 재사용 가능.
- **항목 체크박스 선택 + N차 모드까지 일괄**: 해석 이미지(3D 형상, 모드형상, 지진/풍 변위
  분포도)와 검토 그래프(층간변위비, 층변위, 층전단력 분포, 설계응답스펙트럼, 질량참여율 누적)를
  체크박스로 골라 선택. 모드형상은 "N차"를 고르면 1차부터 N차까지 한 번에 출력.
- **세부 옵션**: "이미지 흰 여백 자동 제거", "지하층 제외" 같은 후처리 옵션을 제공해 산출물의
  즉시 사용성을 높임.
- **순차 처리 + 실패 허용 진행**: 선택한 항목을 순서대로 자동 처리하며 항목별 소요 시간(예:
  3D 형상 1.82초, 층간변위비 검토 5.13초)을 표시. "하나가 실패해도 나머지는 계속됩니다"라고
  명시 — 배치 작업 중 특정 항목 오류가 전체를 중단시키지 않는 내결함성 설계.
- **미리보기 → 저장 2단계 분리**: 출력 완료 후 각 항목을 타일(썸네일)로 먼저 확인(클릭 시 확대)
  하고, 만족스러운 항목만 개별 저장하거나 "모두 저장"으로 폴더에 일괄 저장 — 결과를 보지도
  않고 무작정 파일부터 쌓이는 것을 방지.
- **검토 그래프는 표+차트가 함께 담긴 엑셀로 저장**: "저장된 엑셀은 표와 차트가 함께 들어 있어
  실무 양식에 맞춰 재수정이 가능합니다" — 그래프 이미지 한 장이 아니라, 데이터 표와 차트 3장
  (통합·X방향·Y방향)이 포함된 워크북(`story_drift.xlsx` 등)을 만들어 실무자가 후가공할 수
  있게 함.

## 5. 워크플로우

### Step 1 — GEN 연결

- GenSnap 실행 → 인증 키(MAPI-Key, "GEN 중계서버 인증 키") 입력 → "연결" 클릭.
- 전제 조건: "GEN에서 대상 모델을 열고 해석까지 끝낸 상태여야 합니다. 연결 성공 전에는
  출력·저장 기능을 사용할 수 없습니다." 키는 세션에만 두며 저장하지 않음(GEN 화면에 팝업이
  떠 있으면 연결이 무응답으로 실패할 수 있다는 주의사항도 명시).
- 연결되면 상태 배지가 "연결됨"으로 바뀌고 대상 모델명이 표시됨.
- 자동 인식 결과 확인: 지진(응답스펙트럼) 하중 2개(RX·RY), 풍하중 2개(WX·WY), 진동 모드 15개,
  고유치 해석 결과 확인 가능.

### Step 2 — 출력 항목 선택

- **해석 이미지** 그룹: 3D 형상(숨은선 제거), 모드형상(N차 드롭다운으로 1~N차 일괄), 변위
  분포도(지진 RX/RY), 변위 분포도(풍 WX/WY) — 체크박스, "모두 선택" 지원.
- **검토 그래프 — 기본** 그룹: 층간변위비 검토(지진), 층변위(풍), 층전단력 분포(지진),
  층전단력 분포(풍), 설계응답스펙트럼, 질량참여율(누적).
- **검토 그래프 — 상세** 그룹(접혀 있음, 상세 항목 별도 존재).
- 공통 옵션: 이미지 흰 여백 자동 제거, 지하층 제외.
- "모두 선택"/"모두 해제" 후 "출력 시작" 클릭.

### Step 3 — 자동 출력

- 선택한 항목을 순서대로 자동 처리하며 진행 상태(완료/진행)와 항목별 소요 시간을 표시.
  예: (1/10) 3D 형상 1.82초 → (2~4/10) 모드형상 1~3차 → (5/10) 층간변위비 검토(지진) 5.13초
  → (6/10) 층변위(풍) 3.28초 → (7/10) 층전단력 분포(지진) 2.53초 → (8/10) 층전단력 분포(풍)
  6.09초 → (9/10) 설계응답스펙트럼 6.17초 → (10/10) 질량참여율(누적) 3.73초.
  "지진(응답스펙트럼) 검토 표는 항목당 10~60초 걸릴 수 있습니다"라고 사전 안내.
- 완료 시 "출력을 마쳤습니다. 성공 10건." 요약.

### Step 4 — 결과 확인·저장

- 항목별 썸네일 타일(이미지/그래프)이 그리드로 표시되며, 각 타일에 "완료" 배지와 "저장"(또는
  "엑셀 저장") 버튼이 붙어 있음.
- 타일 클릭 시 확대 보기(3D 형상, 모드형상 1차 등 큰 화면으로 확인).
- 검토 그래프(예: 층간변위비 검토)는 확대 보기에서 통합/X방향/Y방향 탭으로 전환 가능하며,
  그래프에 허용 기준선(허용 0.015 등)이 함께 표시됨.
- 저장: 파일명 접두어(선택), "원본(여백 포함)으로 저장" 여부, "엑셀 파일 포함" 여부를 지정한
  뒤 "모두 저장"으로 폴더에 한 번에 저장. 이미지는 JPG, 그래프는 PNG, 검토 그래프는 엑셀(xlsx)
  형식.
- 개별 항목은 "저장"/"엑셀 저장" 버튼으로 따로 저장 가능(예: 층간변위비 검토(지진) → 엑셀
  저장 → `story_drift.xlsx`, 표 + 차트 3장 통합/Y방향/X방향으로 구성).

## 6. 연계 JSON API 엔드포인트

화면에 정확한 API 이름은 노출되지 않았으나(순수 UI 슬라이드 영상), 출력 항목명이 `docs/manual`
의 결과 테이블·이미지 엔드포인트와 명확히 대응된다:

| 출력 항목 | 추정 API | 문서 위치 |
| --- | --- | --- |
| 3D 형상, 모드형상 | `GET /db/NODE`, `GET /db/ELEM` + `POST /post/table`(`EIGENVALUEMODE`) | [`03_DB_Node_Element.md`](../../manual/03_DB_Node_Element.md), [`20_POST_AnalysisResult_2.md#28-vibration-mode-shape`](../../manual/20_POST_AnalysisResult_2.md#28-vibration-mode-shape) |
| 변위 분포도(지진/풍) | `POST /post/table`(`STORY_DISPLACEMENT_X/Y/COMB`) | [`21_POST_StoryTables.md#2-story-displacement`](../../manual/21_POST_StoryTables.md#2-story-displacement) |
| 층간변위비 검토(지진) | `POST /post/table`(`STORY_DRIFT_X/Y/COMB`) | [`21_POST_StoryTables.md#1-story-drift`](../../manual/21_POST_StoryTables.md#1-story-drift) |
| 층변위(풍) | `POST /post/table`(`STORY_DISPLACEMENT_X/Y/COMB`) | 위와 동일 |
| 층전단력 분포(지진) | `POST /post/table`(`STORY_SHEAR_FOR_RS`) | [`21_POST_StoryTables.md#3-story-shear-force-rs-analysis`](../../manual/21_POST_StoryTables.md#3-story-shear-force-rs-analysis) |
| 질량참여율(누적) | `POST /post/table`(`EIGENVALUEMODE`/`PARTICIPATIONVECTORMODE`) | [`20_POST_AnalysisResult_2.md#28-vibration-mode-shape`](../../manual/20_POST_AnalysisResult_2.md#28-vibration-mode-shape) |
| 지진/풍 하중케이스 자동 인식 | `GET /db/SPLC`, `GET /db/STLD` | [`09_DB_Dynamic_Loads.md#2-dbsplc--response-spectrum-load-cases`](../../manual/09_DB_Dynamic_Loads.md#2-dbsplc--response-spectrum-load-cases), [`06_DB_Static_Loads.md#1-dbstld--static-load-cases`](../../manual/06_DB_Static_Loads.md#1-dbstld--static-load-cases) |

- ⚠️ "설계응답스펙트럼", "층전단력 분포(풍)" 항목은 정확한 `TABLE_TYPE`이 화면에 노출되지
  않아 위 매핑은 명칭 유사성에 근거한 추정이다. 특히 3D 형상·모드형상 "이미지"는 결과 테이블
  (숫자)이 아니라 렌더링 이미지이므로, GEN NX Open API가 직접 이미지를 반환하는지 아니면
  Plug-in이 API로 받은 좌표·변형 데이터를 자체적으로 3D 렌더링하는지는 이 저장소의 `docs/
  manual`만으로는 판단할 수 없다(⚠️ 미확인 — GEN NX Open API에 이미지 캡처 전용 엔드포인트가
  있는지는 별도 확인 필요).

## 7. 입력 데이터 규격

- **선행 조건**: GEN NX에서 대상 모델을 열고 해석까지 완료한 상태.
- **인증**: GEN 중계서버 인증 키(MAPI-Key).
- **출력 항목 선택**: 해석 이미지·검토 그래프 체크박스, 모드형상 차수(N차).
- **저장 옵션**: 파일명 접두어, 원본(여백 포함) 여부, 엑셀 파일 포함 여부.

## 8. 출력 / 생성 결과

- 해석 이미지(JPG): 3D 형상, 모드형상(1~N차), 변위 분포도(지진/풍).
- 검토 그래프(PNG): 층간변위비, 층변위, 층전단력 분포, 설계응답스펙트럼, 질량참여율.
- 검토 그래프 엑셀(xlsx): 표 + 차트(통합/X방향/Y방향) 포함.

## 9. 제약사항 및 한계

- "검토 그래프 — 상세" 그룹은 화면상 접혀 있는 상태로만 노출되어 정확히 어떤 세부 항목이
  포함되는지는 확인되지 않았다(⚠️ 미확인).
- 응답스펙트럼 검토 표는 항목당 10~60초가 걸릴 수 있다고 명시 — 대형 모델에서는 전체 출력이
  꽤 오래 걸릴 수 있음을 시사.
- GEN NX 내장 Plug-in(Apps/My Work)이 아니라 별도 실행파일(exe)로 배포되는 형태이며, 이
  세션에서 다룬 다른 19개 사례와 배포 방식이 다르다 — 원문에 "단일 실행파일(exe) 프…"로
  설명이 잘려 있어 정확한 배포·설치 방식은 원문 재확인이 필요하다(⚠️).
