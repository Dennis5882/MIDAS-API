# BUOY CHECKER 기획문서

> 영상(`docs/plugin_cases/videos/17_BUOY_CHECKER.mp4`, 60fps, 3840×2160, 약 121초)을 6초
> 간격으로 프레임 캡처(총 21장) 후 프레임별 육안 분석 + 화면 상단 큰 자막(단계 제목)을 근거로
> 작성. 원문 아티클(`docs/plugin_cases/articles/17_BUOY_CHECKER.md`)의 4대 기능 설명과 교차
> 확인함. #7(ScaleUp)·#12(OTChecker)·#16(CraneLoader)와 동일 계열의 MIDAS 공식 Apps 4단계
> 마법사형 Plug-in. "연동 원본데이터" 팝업에 실제 API(`GET db/STOR`, `GET db/STLD`, `POST
> TABLE - STORY_AXIAL_FORCE_SUM`, `POST TABLE - REACTIO...`)가 그대로 노출되어 API 매핑
> 근거가 강하다.

## 1. 개요

**Buoy Checker SE**는 GEN NX 해석결과와 사용자가 입력한 설계조건을 바탕으로 구조물의 완공 및
시공단계별 부상(浮上, uplift/buoyancy) 안전성을 검토하는 Plug-in이다. 검토에 필요한 해석결과를
GEN NX에서 자동으로 불러와, 단계별 안전율 검토부터 관리수위(작업 가능 지하수위) 산정, 보고서
출력까지 하나의 연속된 4단계 작업 흐름으로 수행한다.

## 2. 문제 정의

- 지하수위가 높은 부지에서 구조물이 완공 전(자중이 충분히 확보되지 않은 시공 중) 부력에 의해
  뜨는(부상) 것을 막기 위한 검토는, 시공 단계별로 저항 중량(구조체 축력 + 기초 자중)과 부력을
  비교하는 반복 계산이 필요하다.
- 이 검토는 GEN NX 해석결과(층별 축력, 지점반력)를 가져와야 하는데, 결과표와 계산 시트를
  오가며 옮겨 적는 과정에서 데이터 누락·불일치가 발생하기 쉽다.
- 목표 안전율을 만족하기 위해 "지하수위를 얼마까지 낮춰야 하는지"(관리수위)를 역산하는 것도
  수작업으로는 번거롭다.

## 3. 목표 사용자

- 지하수위가 높은 부지의 구조물(지하층 포함 건물 등) 시공단계별 부상 안전성을 검토해야 하는
  구조 엔지니어.
- 굴착·타설 공정별 관리수위를 산정해 시공 계획에 반영해야 하는 실무자.

## 4. 핵심 컨셉 / 차별점

- **상단 상태 안내바 + 맥동 강조 효과**: 4단계(①설계조건 입력 ②연동데이터 확인 ③검토 ④보고서)
  진행 상태와 다음 입력 필드 맥동 강조 — #7·#12·#16과 동일한 신규 사용자 온보딩 패턴을 이
  개발자 생태계 전반에서 반복적으로 채택.
- **GEN NX 결과 자동 연동 + 교차검증**: Story별 고정하중 축력과 기초 지점반력을 각각 다른
  API(층 축력 합 테이블과 지점반력 테이블)로 따로 가져온 뒤, "두 해석결과를 교차검증하여
  데이터의 누락과 불일치 여부를 확인"한다 — 예를 들어 최하층 축력과 지점반력 합계가 일치하는지
  자동 대조(화면 예시: "Story 최하층 35,914.93kN / 지점반력 합계 35,914.93kN / 오차 0.00% ·
  동일"). 두 개의 독립된 API 결과를 서로 검증 수단으로 쓰는 설계가 이 Plug-in만의 특징.
- **저면이 다른 기초 지원**: 기초를 단일기초 또는 저면 레벨이 다른 여러 기초로 나누어 입력 가능
  (기초 1: GL-5.0m, 기초 2: 별도 레벨) — 단차가 있는 기초 형상까지 반영한 부력 검토 개념도를
  실시간으로 갱신해 보여줌.
- **부력 검토 연동 개념도 실시간 시각화**: 지하수위 심도, 콘크리트 단위중량, 기초 자중 가산
  여부, 기초 면적·두께·저면 레벨을 입력하는 즉시 좌측 개념도(지표면 GL, 상부구조 축력 D,
  기초 두께 T·자중, 수두 h, 부력 W.P = q×A)가 실시간으로 갱신되어 입력값의 물리적 의미를
  직관적으로 확인 가능.
- **시공단계별 검토 스택**: "완공시" 기본 검토 외에 "시공단계별"(예: 1F 수평재까지 시공,
  2F 수평재까지 시공 등)을 자유롭게 추가해, 여러 시공 단계를 한 번에 일괄 검토.
- **상세 계산 결과 투명 공개**: 각 단계별로 "01 완공시 OK / 02 1F 수평재까지 시공시 NG"처럼
  판정을 요약하고, 클릭하면 상부구조 축력 D, 기초 자중 산정, D.L 합산, 수두 h 계산, 부력 W.P
  산정, 목표저항력(SF×W.P), UPLIFT CHECK 비교식, 강도설계법(0.9D+1.6W ≥ 0)까지 산식 전체를
  단계별로 노출.
- **관리수위(적정 자하수위) 자동 제안**: 검토 결과가 NG인 단계에 대해 "엔지니어 적용수위"
  섹션에서 "상기 부상 안전성 검토 결과에 따라, 현장 지하수위를 GL- m 이하 조건으로 제안합니다"
  라고 목표 안전율을 만족하는 관리수위를 자동 역산해 제시(원문 3번 기능 "목표 안전율을 만족
  하기 위한 단계별 관리수위를 역산").

## 5. 워크플로우

### Step 0 — Apps에서 실행

- GEN NX `Apps > My Work`에서 "Buoy Checker SE" 실행 → 실행 전 확인: API Connection 상태
  확인, "Story가 정의되고 고정하중 해석결과가 생성된 모델에서 실행하세요."

### Step 1 — 설계조건 입력

- 지하수위 레벨(G.L. 기준, 예 1.5m), 물 단위중량 γw(예 10kN/m³), 콘크리트 단위중량(예
  24kN/m³) 입력.
- "기초 자중을 앞에서 별도 가산" 체크박스.
- 기초정보: 단일기초 또는 저면이 다른 기초(복수) 선택 → 기초 구간별 면적(m²), 두께 T(m),
  저면 레벨(GL-m), 지하부 깊이 H(자동 계산), 수두 h(m) 입력.
- "부력 검토 연동 개념도"가 실시간으로 지상부 구조물·기초·지하수위·부력 W.P를 시각화.

### Step 2 — 연동데이터 확인

- "기초 기준 Story 확인": 각 기초(기초 1, 기초 2)가 GEN NX의 어느 Story 레벨에 대응하는지
  드롭다운으로 확인·수정(예: 기초 1 → B1F·Level -5.0m).
- 고정하중(D) 매핑: 여러 정적하중케이스(Self Weight 포함) 중 고정하중으로 매핑할 케이스 선택
  (여러 개 추가 시 합산). "교차검증" 섹션에서 Story 최하층 축력과 지점반력 합계를 비교해
  오차·불일치 여부 자동 표시.
- Story별 표(Level, 축력 D, 매입 D 등) 확인.
- **"연동 원본데이터" 팝업**에서 5개 취득 항목을 직접 클릭해 원본 API 응답 테이블을 열람 가능
  (6절 참고) — #7 ScaleUp·#12 OTChecker와 동일한 투명성 설계.

### Step 3 — 검토

- 검토 안전율 SF(예 1.20) 입력.
- "검토 시공단계" 표에 "완공시"(기본, 전체 Story) 외 "시공단계별" 행을 "+시공단계 추가"로
  자유롭게 추가하고, 각 행마다 "수행된 시공 범위"를 드롭다운(B1F 수평재까지 / 1F 수평재까지
  / ... / 7F 수평재까지)으로 지정.
- "검토 실행" 클릭 → 단계별 판정(OK/NG) 요약과 "상세 계산 결과 확인" 팝업에서 단계별 전체
  산식(D.L 합산, W.P 산정, UPLIFT CHECK, 0.9D+1.6W 강도설계법 비교)을 확인.
- 예시: "01 완공시 — 상부구조 축력 D=35,914.93kN, 기초 1 기초자중=0.50×24.00×400.00=4,800.00kN,
  D.L=40,714.93kN, 수두 h=max(0, 기초저면-지하수위)=max(0, 5.00-1.50)=3.50m, 부력 q=h×γw=
  35.00kN/m², 부력 W.P=q×A=35.00×400.00=14,000.00kN, 목표저항력=SF×W.P=1.20×14,000.00=
  16,800.00kN, UPLIFT CHECK=40,714.93≥16,800.00kN → OK, 0.9D+1.6W=0.9×40,714.93-1.6×14,000.00=
  14,243.44kN" — "02 1F 수평재까지 시공시"는 NG로 판정됨(축력이 아직 충분히 쌓이지 않은 초기
  시공 단계이므로).

### Step 4 — 보고서

- 프로젝트명·회사명 입력 후 "엔지니어 적용수위" 섹션에서 GL- m 조건(관리수위)을 확인·수정하고
  "엔지니어 적용수위 GL-2.00m 조건으로" 적용.
- "부상 안전성 검토 보고서" 인쇄/PDF: 프로젝트명, 회사명, 작성일자, 검토 개요를 포함한 A4
  보고서 출력.

## 6. 연계 JSON API 엔드포인트

**"연동 원본데이터" 팝업에 5개 취득 항목의 출처 API가 그대로 텍스트로 노출**되어 있어, 확인된
근거로 매핑 가능하다:

| 화면 표시(번호) | 화면 표시 텍스트 | 문서 위치 |
| --- | --- | --- |
| 01 Story 목록 | `GET db/STOR` | [`02_DB_Project_Structure.md#14-dbstor--story-data`](../../manual/02_DB_Project_Structure.md#14-dbstor--story-data) |
| 02 정적하중 케이스 | `GET db/STLD` | [`06_DB_Static_Loads.md#1-dbstld--static-load-cases`](../../manual/06_DB_Static_Loads.md#1-dbstld--static-load-cases) |
| 03 DL·Story 축력 | `POST TABLE · STORY_AXIAL_FORCE_SUM` | [`21_POST_StoryTables.md#9-story-axial-force-sum`](../../manual/21_POST_StoryTables.md#9-story-axial-force-sum) |
| 04 DL·지점반력 | `POST TABLE · REACTIO...`(화면에서 텍스트 일부 잘림) | [`19_POST_AnalysisResult_1.md#1-reaction`](../../manual/19_POST_AnalysisResult_1.md#1-reaction) (`TABLE_TYPE: REACTIONG` 등) |
| 05 DL·지점반력·부가... | (텍스트 일부 잘림, 정확한 항목명 미확인) | ⚠️ 미확인 |

- 03번 항목의 실제 조회 예시("DL·Story 축력" 팝업)에서 Response HEAD가 `Index / Story / Level
  / Story Height / Axial Force Sum of Vertical Elements`로 노출되어, `docs/manual/21_
  POST_StoryTables.md` §9의 `STORY_AXIAL_FORCE_SUM` Response HEAD(`["Index", "Story",
  "Level", "Story Height", "Axial Force Sum of Vertical Elements"]`)와 정확히 일치함을 직접
  확인했다 — 이 세션에서 컬럼 단위까지 실측 대조된 몇 안 되는 사례.
- ⚠️ 04·05번 항목은 화면 좌측 패널 폭 제약으로 텍스트가 "REACTIO...", "부가..." 등으로 잘려
  정확한 전체 문자열은 확인되지 않았다. 04번은 `/db/CONS`가 아니라 `POST TABLE`(결과 테이블)
  경로이므로 `19_POST_AnalysisResult_1.md`의 Reaction 결과 테이블(`REACTIONG` 등)로 추정했다.

## 7. 입력 데이터 규격

- **설계조건**: 지하수위 레벨(GL 기준), 물 단위중량, 콘크리트 단위중량, 기초 자중 가산 여부.
- **기초정보**: 단일 또는 복수(저면 레벨이 다른) 기초의 면적·두께·저면 레벨.
- **검토 조건**: 검토 안전율 SF, 검토할 시공단계 목록(완공시 + 임의 개수의 시공단계별).
- **선행 조건**: Story가 정의되고 고정하중 해석결과가 생성된 GEN NX 모델.

## 8. 출력 / 생성 결과

- 단계별 부상 안전성 판정(OK/NG)과 상세 계산 근거(D.L, W.P, UPLIFT CHECK, 강도설계법 비교).
- 목표 안전율을 만족하는 관리수위(엔지니어 적용수위, GL- m).
- "부상 안전성 검토 보고서"(인쇄/PDF).

## 9. 제약사항 및 한계

- 시공단계는 "N층 수평재까지 시공"이라는 정형화된 구분으로만 선택 가능해 보이며, 골조 외
  비정형 시공 순서(예: 특정 구역만 선타설)를 세밀하게 반영할 수 있는지는 화면상 확인되지
  않았다.
- 교차검증은 최하층 축력과 지점반력의 합계 일치 여부만 확인하는 것으로 보이며, 다른 층의
  세부 불일치까지 자동으로 짚어주는지는 화면에서 명확히 드러나지 않았다.
- "엔지니어 적용수위"는 Plug-in이 제안값을 계산해 보여주지만 최종 반영 여부·수치 조정은
  사용자가 확정해야 한다 — 자동 확정이 아니라 판단 보조.
