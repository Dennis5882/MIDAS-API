# CRANE LOADER 기획문서

> 영상(`docs/plugin_cases/videos/16_CRANE_LOADER.mp4`, 60fps, 3840×2160, 약 142초)을 6초
> 간격으로 프레임 캡처(총 24장) 후 프레임별 육안 분석 + 화면 상단 큰 자막(단계 제목)을 근거로
> 작성. 원문 아티클(`docs/plugin_cases/articles/16_CRANE_LOADER.md`)의 4대 기능 설명과 교차
> 확인함. #7(ScaleUp)·#12(OTChecker)와 동일하게 MIDAS 공식 Apps("My Work") 플랫폼에서 실행되는
> 4단계 마법사형 Plug-in이며, KDS 41 10 15(강구조 설계기준 총칙 — 크레인 하중) 조항 번호까지
> 상세 계산 과정에 그대로 인용되어 있어 계산 근거 투명성이 매우 높다.

## 1. 개요

**Crane Loader SE**는 크레인 제원을 바탕으로 차륜반력과 주행보 지지기둥의 최대 포락반력을
자동으로 산정하는 Plug-in이다. 버튼 한 번으로 크레인의 연직·수평하중에 필요한 하중 케이스를
생성하고, 계산된 절점하중을 GEN NX 모델에 일괄 입력한다. 하중 산정부터 모델 입력, 적용 근거
확인과 구조계산 보고서 작성까지 하나의 연속된 4단계 작업 흐름으로 완료할 수 있다.

## 2. 문제 정의

- 천장 크레인(overhead crane)의 차륜반력·주행보 지지기둥 반력 산정은 크레인 제원(자중, 트롤리
  중량, 정격하중, 스팬 등)과 영향선 해석이 결합된 계산으로, 별도 계산 시트에서 수행한 뒤 그
  결과를 다시 GEN NX에 절점하중으로 옮겨 적어야 하는 반복 작업이다.
- 복수 크레인이 동시에 운용되는 경우 여러 크레인의 하중 조합(포락, envelope)을 고려해야 하는데,
  이를 수작업으로 계산하면 실수하기 쉽다.

## 3. 목표 사용자

- 공장·창고 등 천장 크레인이 설치되는 철골 구조물의 주행보·지지기둥을 설계하는 구조 엔지니어.
- KDS 41 10 15 기준으로 크레인 하중(연직·수평)을 산정해야 하는 실무자.

## 4. 핵심 컨셉 / 차별점

- **상단 상태 안내바 + 맥동 강조 효과**: 4단계(①크레인 자류반력 ②기둥반력 ③절점하중 입력
  ④보고서) 진행 상태를 항상 표시하고 "상단 안내와 맥동효과를 따라 필요한 정보를 순서대로
  입력합니다"라는 신규 사용자 온보딩 — #7 ScaleUp·#12 OTChecker와 동일한 UX 패턴을 이 개발자
  생태계에서 반복적으로 채택하고 있음을 보여줌.
- **복수 크레인 운용 조건 반영**: 운용 크레인 대수(1대/2대/3대)를 선택하면 크레인별 탭(Crane
  1, Crane 2...)이 생겨 각각 제원을 입력하고, 이후 단계에서 여러 크레인의 하중을 함께 고려한
  최대 포락반력을 산정 — 단일 크레인이 아니라 다수 크레인 동시 운용이라는 실무 조건을 정면으로
  다룸.
- **KDS 규정 준수 계산 과정 전체 공개**: 편심 계수(1.25, KDS 41 10 15 (3.9.2))부터 수평
  횡하중(H_T = Σ(f×H_w×n), KDS 41 10 15 (3.9.3))과 주행방향 수평하중(H_L = Σ(f×P_max×C_L×n),
  KDS 41 10 15 (3.9.4))까지, 계산의 각 항이 어느 조항에서 왔는지 산식과 함께 "상세 계산 과정"
  화면에 전부 노출 — 결과값만 주는 게 아니라 검토자가 산출 근거를 조항 단위로 추적할 수 있게 함.
- **기둥 배치를 반영한 영향선 해석**: 기둥 스팬(C1-C2, C2-C3, C3-C4, C4-C5, 균등 간격이면 첫
  값이 나머지에 동일 적용)을 입력하면, 각 크레인의 차륜하중이 영향선을 따라 이동하며 특정
  기둥(예: C3)에 최대 반력이 걸리는 케이스를 자동으로 찾아 시각화(단면도 + 각 기둥별 반력표) —
  "지지기둥별 최대 포락반력을 자동으로 산정"이라는 원문 2번 기능과 정확히 일치.
- **주행보 레일(Rail A/B)별 절점 지정 → 자동 하중 입력**: 3D 모델 화면에서 Rail A·Rail B에
  해당하는 GEN NX 절점을 직접 클릭(복수 적용 가능)하고, 크레인 거더 주행방향(X-X/Y-Y)을
  모델링 좌표계 기준으로 지정한 뒤, 산정된 CL1~CL4±(각 방향·부호별 하중 조합)를 절점하중으로
  일괄 입력.
- **연직 하중케이스와 수평 좌우/주행 하중케이스를 방향·부호별로 분리 생성**: CL1(A열 최대),
  CL2(B열 최대), CL3+/CL3-(주행 직각방향 ±), CL4+/CL4-(주행방향 ±) — 부호가 반대인 수평
  하중까지 별도 케이스로 자동 생성해, 실제 크레인 운행 시 좌우로 흔들리는 하중까지 포괄.
- **산정 근거 보고서**: 적용 조건, 크레인별 제원, 지점 기둥 설정, 차륜반력 산정(영향선 개념도
  포함), 기둥반력 산정(수식+대입값)까지 담긴 "크레인 하중 산정 보고서"를 인쇄/PDF로 즉시 출력.

## 5. 워크플로우

### Step 0 — Apps에서 실행

- GEN NX `Apps > My Work`에서 "Crane Loader SE" 실행 → "실행 전 확인": GEN NX API Settings
  에서 API Connection 상태가 Connect인지 확인 후 Run.
- 주요 기능 요약: "크레인 제원을 기반으로 차륜반력과 기둥 최대 반력을 자동 산정합니다."

### Step 1 — 크레인 자류반력(차륜반력) 계산

- 운용 크레인 수(1대/2대/3대) 선택 → 크레인별 탭 생성.
- 제원 입력 방식: 모델 산출(카탈로그 모델 선택, 예 "5ton·21m") 또는 직접 입력. "반드시 사용
  하시는 제품의 제원을 확인하시기 바랍니다"라는 경고 문구 명시.
- 입력 필드: 정격하중(W), 트롤리 중량(Wt), 크레인 자중(Wg), 크레인 스팬(L), 최소 후크 접근
  거리(a), 차륜 간격, 편측 차륜 수(n), 완축 자류 수(n) — 편심 계수 1.25(KDS 41 10 15 (3.9.2))
  자동 적용.
- "계산" 클릭 → A열/B열 최대 차륜반력(R_A, R_B), 최대 차륜하중(P_max), 충격 적용 최대
  차륜하중(P_v = 충격계수 × P_max)을 크레인 거더 차륜반력 개념도(A/B 지점 반력 다이어그램)와
  함께 산출. 예: R_A=138.55kN, R_B=85.62kN, P_max=69.27kN, P_v=86.59kN.

### Step 2 — 기둥반력 계산

- 배석 모델(핀 지지 등)과 크레인 최소 간격 입력.
- 인접 기둥 중심간 경간(C1-C2, C2-C3, C3-C4, C4-C5) 입력 — "동간격" 체크 시 첫 값이 전체에
  동일 적용.
- "기둥반력 계산" 클릭 → A열·B열 기둥반력을 크레인별(Crane 1/Crane 2, 색상 구분) 단면도와
  최대 지지기둥(예 C3, 총 190.51kN) 화살표 다이어그램으로 시각화.
- 지지기둥을 클릭하면 "시작기둥 C3" 상세 표: CL1(A열 최대)/CL2(B열 최대)/CL3±(주행 직각방향)/
  CL4±(주행방향)별 반력값과 도형화된 직교/주행 방향 하중이 표시됨.
- "상세 계산과정 확인" 버튼 → 각 하중 성분(CL3+/CL3-·CL4+/CL4-)의 산식과 KDS 조항 번호(3.9.3,
  3.9.4)까지 노출된 상세 계산서를 팝업으로 확인 가능.

### Step 3 — 절점하중 입력(GEN NX 모델에 반영)

- 3D 모델 뷰에서 Rail A/Rail B 레일별로 하중을 입력할 GEN NX 절점을 직접 클릭해 선택(복수
  적용 가능) — "Gen NX 선택 절점 모두 가져오기" 또는 개별 클릭, "절점 목록 관리"로 확인/삭제.
- 크레인 거더 주행방향(X-X/Y-Y)을 모델링 좌표계를 참조해 지정.
- "Gen NX 하중 적용" 섹션에서 CL1~CL4± 6개 하중조합 체크박스로 반영 여부 선택, "기존 절점하중
  처리"(삭제 후 입력/유지 후 추가) 옵션 지정.
- "Gen NX 모델에 하중 입력" 클릭 → GEN NX에 `Static Load Cases`(DL/LL 외 CL1, CL2, CL3+, CL3-,
  CL4+, CL4- 6개, Type: Live Load(L))가 자동 생성되고, 각 하중케이스에 Nodal Loads(레일 A·B
  절점 각 1개씩, 총 2개)가 입력됨.
- 트리 메뉴에서 생성된 하중케이스와 절점하중을 직접 선택해 3D 모델 위에 화살표로 시각 확인.

### Step 4 — 보고서

- 프로젝트명·회사명 입력 → "크레인 하중 산정 보고서" 출력.
- 보고서 구성: 표지(적용 기준 KDS 41 10 15 — Wheel Load and Column Reaction, 운용 크레인 수,
  지지 기둥 수, 기둥 간격, 지지 기둥, CL1 조합), 1. 적용 조건, 2. 크레인별 제원(표), 3. 지점
  기둥 설정, 4. 차륜반력 산정(크레인 거더 차륜반력 개념도 + Crane 1/Crane 2 각각의 수식·
  대입값), 5. 기둥반력 산정(크레인 거더 차륜반력 배치도 + Σ 계산).
- "작성자 확인사항" 경고 블록: "본 산출물은 검증 대상 실시를 위한 계산 표준입니다", "보수·
  크레인 제원 사양대로 실제 사용 예정인 하중값 조합수 있습니다(예: 대수 하중조합에 따른 적정
  반영 확인)", "증량정 수정중은 실제 사용조건이 되기 시행할 최종 사용값을 기준으로 산정합니다"
  (⚠️ 화면 해상도상 완전히 판독되지 않는 부분 있음 — 취지는 산출 결과가 실사용 전 검증이
  필요한 계산 초안임을 명시하는 면책 문구로 보임).

## 6. 연계 JSON API 엔드포인트

화면에 정확한 API 호출 로그는 노출되지 않았으나, 최종 GEN NX 결과(Static Load Cases 트리에
CL1~CL4± 6개 Live Load 케이스, 각 2개의 Nodal Loads)로 명확히 대응된다:

| 기능 | 추정 API | 문서 위치 |
| --- | --- | --- |
| 하중케이스 생성(CL1~CL4±) | `POST /db/STLD` | [`06_DB_Static_Loads.md#1-dbstld--static-load-cases`](../../manual/06_DB_Static_Loads.md#1-dbstld--static-load-cases) |
| 절점하중 입력(Rail A/B 절점) | `POST /db/CNLD` | [`06_DB_Static_Loads.md#3-dbcnld--nodal-loads`](../../manual/06_DB_Static_Loads.md#3-dbcnld--nodal-loads) |
| 대상 절점 선택 조회 | `GET /view/SELECT` | [`16_VIEW.md#1-viewselect--select`](../../manual/16_VIEW.md#1-viewselect--select) |
| 기존 절점하중 삭제(선택 시) | `DELETE /db/CNLD` | 위와 동일 |

- ⚠️ 위 매핑은 화면에 표시된 최종 결과(하중케이스 8개 중 6개가 신규 CL1~CL4±, Type: Live
  Load(L), 각 2개의 Nodal Loads)에 근거한 추정이며, 실제 요청 바디(하중값의 방향·부호를 어떻게
  `CNLD`의 필드에 매핑하는지)까지는 화면에 노출되지 않았다.
- 차륜반력·기둥반력 계산 자체(영향선 해석, KDS 41 10 15 (3.9.2)~(3.9.4) 산식)는 GEN NX Open
  API가 제공하는 결과가 아니라 Plug-in이 입력값을 바탕으로 자체 구현한 계산 로직으로 보인다
  — #10(RCBeamDeflectionCheck)의 처짐 계산과 마찬가지로, "API로 최소한의 데이터만 가져오고
  전문 계산은 직접 수행"하는 패턴.

## 7. 입력 데이터 규격

- **크레인 제원**: 정격하중(W), 트롤리 중량(Wt), 크레인 자중(Wg), 크레인 스팬(L), 최소 후크
  접근거리(a), 차륜 간격, 편측 차륜 수, 완축 자류 수(카탈로그 모델 선택 또는 직접 입력).
- **기둥 배치**: 지지 형식(핀 지지 등), 크레인 최소 간격, 인접 기둥 중심간 경간(C1-C2 등).
- **절점 선택**: Rail A/B에 대응하는 GEN NX 모델 절점.
- **주행방향**: X-X 또는 Y-Y(모델링 좌표계 기준).

## 8. 출력 / 생성 결과

- 크레인별 차륜반력(R_A, R_B, P_max, P_v)과 기둥별 최대 포락반력(CL1~CL4±).
- GEN NX 모델에 생성된 Static Load Cases(CL1~CL4±) 및 각 케이스의 Nodal Loads.
- "크레인 하중 산정 보고서"(인쇄/PDF).

## 9. 제약사항 및 한계

- 보고서에 "본 산출물은 검증이 필요한 계산 초안"이라는 취지의 면책 문구가 명시되어 있어,
  실사용 전 엔지니어의 검증을 전제로 설계된 도구다.
- 기둥 배치는 균등 간격(동간격 체크) 또는 4개 구간(C1-C2~C4-C5)까지만 입력 가능한 것으로
  보이며, 5개 초과 기둥 스팬을 다루는 대형 구조물에 대한 지원 범위는 화면상 확인되지 않았다
  (⚠️ 미확인).
- 복수 크레인(최대 3대)의 "동시 운용" 가정이 항상 최악 조건(포락)인지, 실제 운용 시나리오에
  따라 다른 조합도 검토해야 하는지는 엔지니어의 판단이 필요하다.
