# RCBeamDeflectionCheck 기획문서

> 영상(`docs/plugin_cases/videos/10_RCBeamDeflectionCheck.mp4`, 60fps, 1920×1080, 약 192초)을
> 7초 간격으로 프레임 캡처(총 28장) 후 프레임별 육안 분석 + 자막 + Message Window 로그를 근거로
> 작성. 원문 아티클(`docs/plugin_cases/articles/10_RCBeamDeflectionCheck.md`)의 4대 기능 설명과
> 교차 확인함. 산출되는 "처짐 구조 검토" 보고서에 KDS 14 20 30 4.2 계산 과정 전체(Ie,eff, Icr,
> Mcr, 탄성처짐, 장기처짐)가 그대로 노출되어 계산 로직 검증 근거가 매우 강한 사례.

## 1. 개요

**RC Beam Deflection Check**는 MIDAS GEN NX 모델에서 RC 보의 단면·재료·배근과 하중케이스별
해석 모멘트를 API로 불러와, KDS 14 20 30 4.2 기준 유효단면 2차모멘트(Ie, Branson 공식)를
이용한 단기·장기 처짐을 자동 계산하고 허용처짐과 비교한 A4 구조계산서(처짐 검토서)를 출력하는
Plug-in이다.

## 2. 문제 정의

- 구조 설계 실무에서 RC 보의 처짐 검토는 필수적이지만, 유효단면 2차모멘트(Ie,eff) 산정, 균열
  단면 2차모멘트(Icr) 계산, 크리프·건조수축에 의한 장기처짐 배율(λΔ) 적용 등 다단계 계산을
  수작업으로 반복하기엔 번거롭다.
- GEN NX 모델에 이미 존재하는 단면·재료·배근·모멘트 정보를 검토서 작성을 위해 다시 옮겨 적어야
  하는 비효율이 있다.

## 3. 목표 사용자

- KDS 14 20 30(콘크리트구조 사용성 설계기준) 4.2항에 따라 RC 보의 처짐을 검토해야 하는 구조
  설계자.
- 단순보·연속보·캔틸레보 등 다양한 지지조건의 처짐 검토서를 반복 작성해야 하는 실무자.

## 4. 핵심 컨셉 / 차별점

- **모델 데이터 자동 취득**: GEN NX 모델링 화면에서 검토할 보를 직접 선택("Select beam load"
  버튼)하면, 그 보의 단면(b, h), 재료 강도(fck, fy), 배근(As, 층별 개수·규격), 부재 길이(L)가
  모두 자동으로 불러와진다.
- **하중케이스를 고정하중/활하중으로 그룹핑**: 여러 정적 하중케이스(DL_self, DL_finish, LL-1,
  LL-2 등) 중 어떤 것이 고정하중(D)이고 어떤 것이 활하중(L)인지 사용자가 직접 매핑해, 처짐
  계산에 필요한 M_D·M_L·M_D+L·M_sus(지속하중모멘트)를 구성한다.
- **계산 조건을 세부 옵션으로 노출**: 지지조건(단순보/연속보/캔틸레보 등), 보 단면(직사각형보/
  T형보), 플랜지폭·두께(T형보 선택 시), 단기/장기 허용처짐 기준(L/360, L/480 등 사용자 지정),
  지속하중비율(%), 재하기간(D)(60개월 이상 λ=2.0 등), 피복두께, 지속하중 방식(KDS[14 20 30]
  준수)까지 세밀하게 조정 가능.
- **T형보 유효폭 반영**: 직사각형보뿐 아니라 T형보를 선택하면 플랜지폭(bf)·플랜지두께(hf)를
  입력해 유효단면 계산에 반영 — 동일 보 부재를 다른 단면 가정으로 재검토하는 시연도 포함.
- **NG 시 즉시 배근 수정 → GEN NX 반영 → 재검토 루프**: 검토 결과가 NG(장기처짐 초과)로
  나오면, 같은 창에서 배근(층별 철근 개수·규격)을 직접 수정하고 "Rebar update" 버튼을 눌러
  GEN NX 모델에 즉시 반영(`✓ GEN NX 반영` 표시)한 뒤 재검토를 실행 — 검토서 작성과 배근 보강이
  한 화면에서 반복 가능하다.
- **A4 처짐 검토서 자동 생성**: KDS 14 20 30 4.2 계산 전 과정(하중 및 모멘트 산정 → 균열 발생
  여부 판정 → 균열단면 2차모멘트 Icr 산정 → 유효단면 2차모멘트 Ie,eff 산정 → 탄성처짐 → 장기
  처짐 → 처짐 검토 OK/NG)을 표·수식과 함께 A4 1페이지 보고서로 인쇄/PDF 저장.

## 5. 워크플로우

### Step 1 — API 연결

- "RC Beam Deflection Check" 창에서 `Base URL`, `MAPI Key` 입력 후 연결.

### Step 2 — 하중케이스 매핑 및 계산 조건 설정

- 고정하중(DL) 목록에 `DL_self`, `DL_finish` 등을 추가/선택, 활하중(LL) 목록에 `LL-1`, `LL-2`
  등을 추가/선택("+추가" 버튼으로 여러 케이스 조합 가능, 주석: "여러 개 추가 시 실행됩니다
  [M_D = M_D1 + M_D2 ...]").
- 계산 조건: 지지조건(단순보), 보 단면(직사각형보/T형보), 플랜지폭·두께(mm), 단기 허용처짐
  (L/360), 지속하중율(%, 예 50), 장기 허용처짐(L/480), 재하기간(D)(예 "60개월 이상(λ×2.0)"),
  피복두께(mm, 예 40), 지속하중 방식(예 KDS[14 20 30]).

### Step 3 — 검토 대상 보 선택 및 데이터 자동 취득

- "Select beam load" 클릭 → 모델링 화면에서 보 요소 선택(하이라이트 표시) → "부재명, 단면
  치수, 콘크리트 강도, 철근 강도, 부재 길이가 자동으로 불러와지며" 보 부재 목록 표에 반영
  (Ele No., Section, b, h, fck, fy, L 컬럼).
- 체크박스로 검토할 보를 선택하면 그 보의 배근 정보(위치별: End(i)/Middle(m)/End(j), 층별
  As Top/Bot, 철근 규격 드롭다운)와 고정하중·활하중 모멘트(Mu_D, Mu_L)가 함께 표시된다.

### Step 4 — 처짐 검토 실행

- "처짐 검토 실행" 클릭 → 새 창(팝업)에 "처짐 검토 결과" 요약(예: "OK 0 · NG 1") 및 부재별
  상세 보고서가 즉시 생성됨.
- 보고서 구성(#1 예시 — 8m 단순보, 직사각형 600×800, fck 24MPa, fy 500MPa):
  1. **하중 및 모멘트 산정**: 위치별(Middle) M_DL, M_LL, M_D+L, M_sus(지속하중비 50%) 표.
  2. **균열 발생 여부 판정**: f_r(=0.63√fck), I_g(=bh³/12), M_cr(+)(=f_r·Ig/yt,pos).
  3. **균열단면 2차모멘트(Icr) 산정**: 환산탄성계수비 n(=Es/Ec), 압축측·인장측 철근량, kd,
     I_cr(mm⁴).
  4. **유효단면 2차모멘트(Ie,eff) 산정**: KDS 가중평균 `Ie,eff = Iu·m` 방식, 위치별(D)/(D+L)/
     (sus) 3열 표.
  5. **탄성처짐**: K(D+L) 계수, δ_D+L, δ_D, δ_L = δ_D+L − δ_D.
  6. **장기처짐**: 시간경과계수 ξ(재하기간별, 60개월 이상=2.0), 압축철근비 ρ', λΔ(=ξ/(1+50ρ')),
     δ_sus, δ_cp+sh(=λΔ·δ_sus), δ_cp+sh+δ_L(=장기처짐 합계).
  7. **처짐 검토**: 단기처짐(예 9.64mm < δa=L/360=22.22mm → OK), 장기처짐(예 33.65mm <
     δa=L/480=16.67mm 초과 → **NG**, "장기처짐에 대해 보강이 필요한 것을 확인할 수 있습니다").

### Step 5 — NG 시 배근 보강 및 재검토

- NG로 판정된 보의 배근표에서 층별 철근 규격/개수를 직접 수정(예: 하부근 5-D22 → 7-D22로
  증량).
- "Rebar update" 클릭 → 모델링 화면에 즉시 반영 확인 표시(`✓ GEN NX 반영`).
- "처짐 검토 실행" 재실행 → 배근 증량 후 상부근 7-D22(2,710mm²), 하부근 11-D22(8,516mm²)로
  재계산 → 결과 OK 1 · NG 0으로 전환(단기 3.97mm < 22.22mm, 장기 15.24mm < 16.67mm, 모두
  OK) — "장기처짐에 대해 문제가 없음이 확인됩니다."

### Step 6 — T형보로 단면 조건 변경해 재시연

- 두 번째 보(10m, 직사각형 800×800)에 대해 "해당 보는 T형보 유효플랜지 폭·두께를 적용하여
  검토해보겠습니다" — 보 단면을 T형보로 전환, 플랜지폭 2500mm·플랜지두께 150mm 입력 후 재검토.
- NG(초기 결과) → 배근 수정(상부근 10-D22, 하부근 6+11-D22 2단 배근 등) → "Rebar update" →
  재검토 → 결과 확인.

### Step 7 — 결과 인쇄/PDF 저장

- "인쇄/PDF 저장" 버튼 → 프린터 선택(예 SINDOH D450 또는 Microsoft Print to PDF), 페이지·
  색상·양면 인쇄 옵션과 함께 검토 결과 페이지 미리보기 후 저장/인쇄.
- 마무리 자막: "이번 시연에서는 단순보를 기준으로 보여드렸지만, 다양한 케이스에 적용할 수
  있습니다" — 연속보·캔틸레보 등 다른 지지조건에도 동일 로직이 적용 가능함을 시사(단, 실제
  시연은 단순보로만 진행됨).

## 6. 연계 JSON API 엔드포인트

화면에 정확한 엔드포인트 이름이 텍스트로 노출되지는 않았으나, GEN NX Tables 트리(Tree Menu 2)에
`Design Tables > Concrete Design > Modify Beam Rebar Data`가 직접 노출되고 Message Window에
`Start Writing RC Beam Design Result to Table` / `Start Writing RC Beam Checking Result to
Table` / `End Code Checking by KDS 41 20 : 2022` 로그가 그대로 출력되어, #9(RCRebarOptimizer)
에서 확인한 동일 RC 설계 API 계열임을 알 수 있다:

| 기능 | 추정 API | 문서 위치 |
| --- | --- | --- |
| 보 배근 정보 조회/수정("Rebar update") | `DESIGN/RC/KDS-41-20-2022/DCRM-BEAM` | [`26_Design_RC_KDS41202022.md#29-designrckds-41-20-2022dcrm-beam--보-부재별-철근-설계기준`](../../manual/26_Design_RC_KDS41202022.md#29-designrckds-41-20-2022dcrm-beam--보-부재별-철근-설계기준) |
| RC 보 설계 수행/결과표(모멘트·배근 조회) | `BD-ANAL` / `BD-TABLE` | [`26_Design_RC_KDS41202022.md#39-designrckds-41-20-2022bd-anal--rc-보-설계-수행`](../../manual/26_Design_RC_KDS41202022.md#39-designrckds-41-20-2022bd-anal--rc-보-설계-수행), [`26_Design_RC_KDS41202022.md#40-designrckds-41-20-2022bd-table--rc-보-설계-테이블`](../../manual/26_Design_RC_KDS41202022.md#40-designrckds-41-20-2022bd-table--rc-보-설계-테이블) |
| 단면/부재 정보(b, h, L) | `GET /db/SECT`, `GET /db/ELEM` | [`04_DB_Properties.md#12-dbsect`](../../manual/04_DB_Properties.md#12-dbsect), [`03_DB_Node_Element.md#2-dbelem`](../../manual/03_DB_Node_Element.md#2-dbelem) |
| 재료 강도(fck, fy) | `GET /db/MATL` | [`04_DB_Properties.md#1-dbmatl`](../../manual/04_DB_Properties.md#1-dbmatl) |
| 하중케이스별 해석 모멘트 | `POST /post/table`(부재력 계열 테이블) | [`20_POST_AnalysisResult_2.md`](../../manual/20_POST_AnalysisResult_2.md) (Beam Force 계열) |

- ⚠️ 처짐 계산 자체(Ie,eff, Icr, λΔ 등 KDS 14 20 30 4.2 산식)는 GEN NX Open API가 직접
  제공하는 결과가 아니라, Plug-in이 API로 취득한 단면·재료·배근·모멘트 원시 데이터를 바탕으로
  **자체 구현한 계산 로직**으로 보인다 — `docs/manual`에 "처짐(Deflection)"을 직접 계산해주는
  전용 POST 엔드포인트는 없으며, 이는 이 Plug-in의 핵심 부가가치(API로 데이터만 가져오고 계산은
  직접 수행)임을 시사한다.

## 7. 입력 데이터 규격

- **하중케이스 매핑**: 고정하중(DL)·활하중(LL) 각각 1개 이상 지정.
- **계산 조건**: 지지조건, 보 단면 타입(직사각형/T형), 단기·장기 허용처짐 기준(L/n 형태), 지속
  하중비율(%), 재하기간(λ 계수), 피복두께(mm).
- **검토 대상 보**: GEN NX 모델링 화면에서 직접 선택.

## 8. 출력 / 생성 결과

- 처짐 검토 결과 요약(OK/NG 건수) 및 부재별 상세 계산 보고서.
- 배근 보강 시 GEN NX 모델에 반영된 수정 배근 데이터(`DCRM-BEAM`).
- A4 처짐 구조 검토서(인쇄/PDF).

## 9. 제약사항 및 한계

- 실제 시연은 단순보(Simple Beam) 지지조건으로만 진행되었고, 연속보·캔틸레보 등 다른 지지
  조건에 대한 계산 로직 차이는 화면에서 직접 확인되지 않았다(자막상 "적용 가능"이라고만 언급).
- 처짐 계산 자체는 API가 아닌 Plug-in의 자체 구현 로직으로 보이므로, GEN NX 정식 계산 결과와
  100% 일치한다는 보증은 없다(⚠️ Plug-in 자체 검증 필요 — 원문에도 계산 정확성에 대한 별도
  보증 문구는 없음).
- 지속하중비율(%)이나 재하기간(λ 계수)은 사용자가 직접 입력해야 하며, 이 값이 실제 설계
  조건과 맞는지는 엔지니어가 판단해야 한다.
