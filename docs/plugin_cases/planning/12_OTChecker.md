# OTChecker 기획문서

> 영상(`docs/plugin_cases/videos/12_OTChecker.mp4`, 60fps, 3840×2160, 약 133초)을 6초 간격으로
> 프레임 캡처(총 23장) 후 프레임별 육안 분석 + 화면 상단 큰 자막(단계 제목)을 근거로 작성. 원문
> 아티클(`docs/plugin_cases/articles/12_OTChecker.md`)의 4대 기능 설명과 교차 확인함. #7(ScaleUp)
> 과 동일하게 MIDAS 공식 Apps("My Work") 플랫폼에서 실행되는 4단계 마법사형 Plug-in. "GEN NX
> 원본 데이터 확인" 드롭다운에 실제 호출 API(`GET db/STLD`, `GET db/SPLC`, `POST TABLE ·
> REACTIONS`, `POST TABLE · OVERTURNING_MOMENT`)가 그대로 텍스트로 노출되어 API 매핑 근거가
> 매우 강한 사례.

## 1. 개요

**OT Checker SE(Over Turning Checker)**는 GEN NX 해석결과와 사용자가 입력한 설계조건을
바탕으로 풍하중 및 지진하중에 대한 구조물의 전도(Overturning) 안정성을 검토하는 Plug-in이다.
전도 검토에 필요한 고정하중 지점반력과 전도모멘트를 GEN NX에서 자동으로 불러와, 해석결과 확인
→ 전도 안정성 검토 → 지배 조건 판정 → 보고서 출력까지 하나의 연속된 4단계 흐름으로 수행한다.

## 2. 문제 정의

- 풍하중·지진하중에 의한 구조물 전도 검토는 GEN NX 해석 결과(고정하중 반력, 각 하중케이스별
  전도모멘트)를 별도 계산 시트로 옮겨 적어 저항모멘트·안전율을 산정해야 하는 반복 작업이다.
- 강도설계법과 허용응력설계법 등 검토 방법에 따라 하중조합·안전율 기준이 달라, 매번 수식을
  재구성하는 것이 번거롭다.
- 모델에 포함되지 않은 기초·벽체 자중(저항모멘트에 기여하는 요소)을 별도로 반영해야 하는데,
  이를 누락하기 쉽다.

## 3. 목표 사용자

- 풍하중·지진하중에 대한 구조물 전도 안정성을 KDS 하중조합 또는 안전율 기준으로 검토해야 하는
  구조 설계자.
- 처음 이 작업 흐름을 접하는 신규 사용자를 포함(원문 4대 기능의 1번이 "처음 사용자를 위한
  단계별 안내").

## 4. 핵심 컨셉 / 차별점

- **상단 상태 안내바 + 맥동 강조 효과**: 4단계(①설계조건 입력 ②연동데이터 확인 ③검토 ④보고서)
  진행 상태를 항상 표시하고, 다음 입력 필드를 파란색 안내 카드로 맥동 강조 — #7 ScaleUp과 동일한
  온보딩 설계 패턴.
- **회전팔 거리(Lx·Ly) 개념 가이드 내장**: "Lx·Ly는 어디까지의 거리인가?"를 대칭 평면(질량중심이
  중앙)/비대칭 평면(질량중심이 편심) 2가지 CASE 다이어그램으로 직접 설명해, 사용자가 착각하기
  쉬운 회전팔 거리 정의를 시각적으로 명확히 한다.
- **검토방법 2종 동시 선택 가능**: KDS 하중조합 검토(강도설계법/허용응력설계법 중 선택)와
  안전율 검토(요구 안전율 SF_req, 기본값 1.5)를 중복 선택해 각 방법별 판정 카드를 별도로 받을
  수 있다.
- **모델 외 요소 자중 반영**: 기초 자중(면적 A, 두께 t, 단위중량 γ → 자동 계산 W)과 벽체
  자중(평면 총길이 L, 벽체 두께 t, 층고 H, 단위중량 γ)을 여러 개 추가할 수 있어, GEN NX 모델에
  실제로 모델링되지 않은 기초·옹벽의 저항모멘트 기여분을 놓치지 않게 한다. "모델에 포함된
  부재를 다시 입력하면 중량이 중복으로 더해집니다"라는 경고도 명시.
- **구조형식별 전도 개념도(계산에 영향 없는 보고서 첨부용)**: 철골구조/철근콘크리트구조/기초구조
  3종 중 선택해 다이어그램을 보고서에 자동 첨부하되, "보고서 첨부용 이미지로 계산에 영향을
  미치지 않습니다"라고 명시 — 계산 로직과 문서화 요소를 UI에서 분리해 사용자 혼란을 방지.
- **연동 원본 데이터 직접 열람 가능**: "GEN NX 원본 데이터 확인" 드롭다운에서 실제 취득한 6개
  원본 테이블(정적 하중케이스, 응답스펙트럼 하중케이스, 고정하중 지점반력, 방향별 전도모멘트
  4종)을 하나씩 선택해 원본 응답 데이터를 직접 확인 가능 — #7 ScaleUp의 "GEN NX 데이터 출처와
  원본 테이블" 기능과 동일한 투명성 설계 패턴.
- **지배 조건 판정 및 안정 확보 필요 고정하중 자동 산출**: 각 하중 방향·검토방법 조합별로
  OK/NG를 판정하고, NG인 경우 "안정 확보에 필요한 고정하중"(예: 175.94 kN 추가 필요)을 막대
  그래프로 시각화 — 단순 판정을 넘어 "얼마나 더 필요한지"까지 정량 제시.

## 5. 워크플로우

### Step 0 — Apps에서 실행

- GEN NX `Apps` 탭에서 "OT Checker SE" 선택 → 실행 전 확인: "GEN NX API Settings에서 API
  Connection 상태가 Connect인지 확인한 후 Run 버튼을 누르세요", "고정하중, 풍하중 및 시진하중
  해석결과가 생성된 모델에서 실행하세요."

### Step 1 — 설계조건 입력

- **전도 검토 입력**: Lx(질량중심에서 X방향 최전 끝단까지 거리, 질량중심이 중앙일 때 X축/2),
  Ly(동일하게 Y방향) — "Lx·Ly 입력 도움말" 버튼으로 대칭/비대칭 평면 2-CASE 가이드 팝업 제공.
- **검토방법**: `KDS 하중조합 검토`(강도설계법/허용응력설계법 선택) + `안전율 검토`(요구
  안전율 SF_req, 기본 1.5) — 중복 선택 가능, 각 방법별로 별도 카드에서 결과 표시.
- **모델 외 요소 자중**: 기초 자중(+기초 추가), 벽체 자중(+벽체 추가) — 면적·두께·단위중량으로
  W 자동 계산.
- **구조형식별 전도 개념도**: 철골구조/철근콘크리트구조/기초구조 선택(보고서 첨부용, 계산
  무관). 선택 시 모델 고정하중 ΣD.L, 총 연직하중 ΣV, 기초 자중 Wf가 개념도와 함께 요약 표시.

### Step 2 — 연동데이터 확인 (GEN NX 결과 자동 연동)

- "GEN NX 해석결과 불러오기" 버튼 클릭 → 고정하중 반력(ΣD.L, 고정하중 케이스: 기본 DEAD
  LOAD, 직접 입력도 가능) 자동 조회.
- **하중케이스 매핑 및 Mo**: 풍하중 X/Y방향, 지진하중 X/Y방향 각각에 대해 GEN NX 케이스를
  드롭다운으로 선택(예: WX1[ST], WY1[ST], EX1[ST], EY1[ST])하면 각 방향의 전도모멘트(Mo)가
  자동 조회됨(직접 입력으로 대체도 가능). 지진하중 Y방향 기초층 검토모멘트가 0일 경우 "지진
  하중 Y방향 기초층 검토모멘트가 0입니다. 세부설정 및 방향을 확인해주세요"라는 경고를 자동
  표시 — 잘못된 하중케이스 선택을 사전에 감지.
- **GEN NX 원본 데이터 확인**: 드롭다운에서 원본 테이블을 선택해 실제 조회 결과를 직접 열람 —
  이 목록에 아래 6절 표의 API 이름이 그대로 노출됨.

### Step 3 — 검토 (전도 안정성 검토)

- "검토하기" 버튼 → ΣD.L(84.53) + ΣW(86.40) = ΣV(170.93 kN) 합산 확인 후 실행.
- **STABILITY MARGIN**(안정 확보에 필요한 고정하중): 방향별(풍하중 X/Y, 지진하중 X/Y)로 현재
  ΣD.L·필요 ΣD.L·추가 필요 고정하중을 막대그래프로 표시. 예: 풍하중 X방향 "고정하중 175.94kN
  추가 필요"(NG), 지진하중 X/Y방향은 추가 필요 0.00kN(OK).
- **방향별 저항모멘트 Mr**, **케이스별 검토 결과**(강도설계법/허용응력설계법 등): 각 카드에
  Mo, 안전율 S.F, KDS 조합식(예: 0.9D+1.0W), KDS 검토비, 최고 ΔM_req, KDS 부족 저항 표시.
  예: 풍하중 X방향 — Mo 462.50kN·m, 안전율 S.F 0.74(NG), KDS 조합 0.9D+1.0W, KDS 검토비 1.50
  (NG), 최고 ΔM_req 351.89kN·m, KDS 부족 저항 154.83kN. 지진하중 X/Y방향은 모두 OK(S.F 3.42,
  KDS 검토비 0.33).
- **DETAILED CALCULATION**(상세 계산 결과): 방향별로 `Mo = 462.50kN·m`, `Mr = ΣV × L =
  170.93 × 2.00 = 341.85 kN·m`, `S.F = Mr / Mo = 0.74`, `0.9D + 1.0W · 검토비 1.50`, `안정
  필요 ΣV = 346.87 kN`, `목표 ΣD.L = 260.47 kN`, "고정하중 175.94 kN 추가 필요" 순으로 산식이
  그대로 노출됨 — 계산 과정이 블랙박스가 아니라 각 단계의 수식과 대입값을 모두 확인 가능.

### Step 4 — 보고서 출력

- 프로젝트명, 회사명(선택) 입력 후 "인쇄/PDF" 버튼.
- 보고서("전도 안정성 검토 계산서") 구성: 1. 연직하중 및 저항모멘트(ΣD.L/ΣW/ΣV 요약, 검토법,
  Mr,x/Mr,y 산식), 2. 전도 검토 개념도·철골구조(그림+수치 요약), 3. 모델 외 요소 자중(3-1 기초
  자중, 3-2 벽체 자중 상세 표) 등 — 입력 조건·해석결과·검토 결과·산정 근거를 A4 문서로 정리.

## 6. 연계 JSON API 엔드포인트

**"GEN NX 원본 데이터 확인" 드롭다운에 실제 호출 API가 그대로 텍스트로 노출**되어 있어, 이
Plug-in은 추정이 아니라 화면에 직접 확인된 근거로 매핑 가능하다:

| 화면 표시 | 문서 위치 |
| --- | --- |
| `정적 하중케이스 · GET db/STLD` | [`06_DB_Static_Loads.md#1-dbstld--static-load-cases`](../../manual/06_DB_Static_Loads.md#1-dbstld--static-load-cases) |
| `응답스펙트럼 하중케이스 · GET db/SPLC` | [`09_DB_Dynamic_Loads.md#2-dbsplc--response-spectrum-load-cases`](../../manual/09_DB_Dynamic_Loads.md#2-dbsplc--response-spectrum-load-cases) |
| `고정하중 지점반력 · POST TABLE · REACTIONS` | [`19_POST_AnalysisResult_1.md#1-reaction`](../../manual/19_POST_AnalysisResult_1.md#1-reaction) (`TABLE_TYPE: REACTIONG` 등) |
| `풍하중/지진하중 X·Y방향 전도모멘트 · POST TABLE · OVERTURNING_MOMENT · {LOAD_CASE}(ST)` | [`21_POST_StoryTables.md#8-overturning-moment`](../../manual/21_POST_StoryTables.md#8-overturning-moment) |

- ⚠️ 화면 드롭다운의 "고정하중 지점반력 · POST TABLE · REACTIONS"는 표기가 다소 축약되어
  있으며, `docs/manual`의 정확한 `TABLE_TYPE` 값은 `REACTIONG`(Global) / `REACTIONL`(Local) /
  `REACTIONSURFACESPRING`(면스프링 국부) 3종으로 나뉜다. 전역 좌표계 지점반력이 필요한 이
  용도상 `REACTIONG`을 사용하는 것으로 추정되나, 화면에 정확한 `TABLE_TYPE` 문자열까지는
  노출되지 않았다.
- `OVERTURNING_MOMENT`는 `docs/manual/21_POST_StoryTables.md` §8에 문서화되어 있으며, 이
  엔드포인트에는 `ADDITIONAL.SET_OVERTURNING_MOMENT_PARAMS`(응답스펙트럼 스케일 계수, 감소계수
  산정 방식 FIXED/AUTO)라는 고급 옵션이 있다 — Plug-in이 이 옵션을 어떻게 활용하는지는 화면에
  노출되지 않았다.

## 7. 입력 데이터 규격

- **Lx, Ly**: 질량중심 기준 회전팔 거리(m).
- **검토방법**: KDS 하중조합(강도설계법/허용응력설계법) 및/또는 안전율(SF_req, 기본 1.5).
- **모델 외 요소 자중**: 기초(면적, 두께, 단위중량), 벽체(평면 총길이, 두께, 층고, 단위중량) —
  0개 이상.
- **하중케이스 매핑**: 풍하중 X/Y, 지진하중 X/Y 각각 GEN NX 케이스 선택 또는 Mo 직접 입력.

## 8. 출력 / 생성 결과

- 방향별·검토방법별 전도 안정성 판정(OK/NG), 안전율, KDS 검토비.
- NG 시 "안정 확보에 필요한 추가 고정하중" 정량값.
- "전도 안정성 검토 계산서" A4 보고서(인쇄/PDF).

## 9. 제약사항 및 한계

- 지진하중 Y방향처럼 매핑한 하중케이스의 전도모멘트가 0으로 조회되는 경우가 실제로 발생함을
  화면이 직접 보여준다 — 하중케이스 선택이 실제 해석 결과와 맞는지 사용자가 별도로 검증해야
  하며, Plug-in이 자동으로 올바른 케이스를 추천해주지는 않는다(경고만 표시).
- 구조형식별 전도 개념도는 "계산에 영향을 미치지 않는" 순수 보고서 삽화이므로, 실제 저항모멘트
  산정 로직(ΣV × L)과는 무관하다 — 사용자가 이를 계산 옵션으로 오인하지 않도록 주의가 필요.
  다만 이는 Plug-in이 스스로 명시한 내용이라 위험도가 낮다.
- 모델 외 요소 자중을 입력할 때 모델에 이미 포함된 부재를 중복 입력하면 저항모멘트가 과대
  산정될 위험이 있음을 Plug-in이 직접 경고하지만, 이 중복 여부를 자동으로 감지하지는 못한다.
