# SolarStructureModeling 기획문서

> 영상(`docs/plugin_cases/videos/20_SolarStructureModeling.mp4`, 30fps, 1920×1080, 약 179초)을
> 8초 간격으로 프레임 캡처(총 23장) 후 프레임별 육안 분석 + 자막(VREW 자동 생성 자막으로 추정)
> 을 근거로 작성. 원문 아티클(`docs/plugin_cases/articles/20_SolarStructureModeling.md`)의 4대
> 기능 설명과 교차 확인함. 이 세션에서 다룬 20개 사례 중 마지막이며, 풍하중 계산 근거(KDS 41
> 12:00:2022)가 산식 단계별로 화면에 그대로 노출되어 하중 자동 계산 로직의 투명성이 매우
> 높다.

## 1. 개요

**Solar Structure Modeling**은 MIDAS GEN NX에서 태양광 구조물 형식(CASE 1~4)을 선택하고
치수·재료·단면을 입력하면 절점, 보 요소, 경계조건을 GEN NX 모델에 자동 생성하는 Plug-in
이다. 설치 형식과 주요 치수만 입력하면 기둥·지붕보·브레이스·퍼린 등 모든 구성 요소의 절점과
요소가 자동으로 계산·생성되고, 중력하중(고정·적재·적설)과 KDS 기반 풍하중까지 자동 계산·
배정된다.

## 2. 문제 정의

- 태양광 구조물(단기둥형·1스팬·다스팬·지붕 위 설치형)은 기둥·지붕보·브레이스·퍼린 등 여러
  종류의 부재가 반복 배치되는 정형화된 구조인데, 수작업 모델링은 절점 번호 계산, 부재 좌표
  결정, 경계조건 입력 등 반복 작업이 많아 시간이 오래 걸린다.
- 태양광 구조물의 풍하중은 KDS 41 12:00:2022 기준으로 골조용/외장재용을 나누어 산정해야
  하는데, 이 계산 자체가 복잡해 수작업 시 오류가 발생하기 쉽다.

## 3. 목표 사용자

- 태양광 발전 구조물(지상 거치대, 지붕 위 설치형 등)을 GEN NX로 반복 모델링하는 구조
  설계자.
- KDS 41 12:00:2022 기준 풍하중 산정 근거를 명확히 남겨야 하는 실무자.

## 4. 핵심 컨셉 / 차별점

- **4가지 설치 형식(CASE) 선택형 템플릿**: CASE 1(단기둥 태양광구조물), CASE 2(1SPAN 태양광
  구조물), CASE 3(다SPAN 태양광구조물), CASE 4(지붕 위 태양광구조물) 중 실제 해석할 태양광
  모듈과 같은 형식을 그림 아이콘으로 선택 — 형식에 따라 이후 입력 필드 구성 자체가 달라짐.
- **재료·단면을 GEN NX에서 직접 불러오기**: "GEN NX에서 불러오기" 버튼으로 현재 모델에 이미
  정의된 재료·단면을 재료(전체)/기둥 단면/지붕보 단면/브레이스 단면/퍼린 단면 5개 슬롯에
  각각 배정 가능 — 신규 정의 없이 기존 표준 부재를 재사용하는 경로 제공.
  (재료·단면이 아직 없다면 GEN NX 네이티브 `Material Data`/`Section Data` 창을 직접 열어 새로
  정의한 뒤 다시 불러오는 흐름도 시연됨.)
  - 이 경우 정의한 재료: SS275(강재), 기둥 단면 B100×100×2.3(각형강관), 지붕보 단면
    B100×100×2.3, 브레이스/퍼린 단면 LC-100×50×20×2.3(경량 형강 Cold Formed Channel).
- **입면도·배면도 실시간 미리보기**: 입력한 모든 치수(기둥 높이 H, 경사각 θ, 지붕보 길이
  RL/RR, 브레이스1(각관, TRUSS)·브레이스2(우측, TRUSS)의 부재 높이·각도, 퍼린 핀 수, Y방향
  열 수·열 간격, 가로브레이스 하단/상단 높이)를 입력하는 즉시 좌측 입면도·배면도가 갱신되어
  형상을 직관적으로 확인할 수 있음(범례: 기둥/지붕보/브레이스(TRUSS)/퍼린 색상 구분).
- **경계조건 프리셋**: 기둥 하단 지점을 "핀(이동 구속, 회전 자유)" 등 프리셋으로 선택.
- **하중값 자동 생성(고정·적재·적설)**: "면하중 자동 생성" 체크 시 고정하중(Dead
  Load)·적재하중(Live Load)·설하중(Snow Load)을 kN/m² 단위로 입력하면 One-Way 분배(재하
  방향)·수평투영 기준으로 자동 배정.
- **KDS 41 12:00:2022 풍하중 완전 자동 계산**: "풍하중 자동 생성" 체크 후 기본풍속(Vs)과
  지표면조도구분만 입력하면, 모듈 형상(경사각 12.0°, 순골조율 등)을 반영해 4개 케이스(WL1
  β=0° 가/풍상, WL2 β=0° 나/풍하, WL3 β=180° 가/역풍, WL4 β=180° 나/역풍)의 풍상/풍하
  순압력계수(C_NW/C_NL)와 설계압력(P_W/P_L)을 자동 산출.
  - **"계산서 출력" 버튼**으로 산정 근거 전체를 펼쳐볼 수 있으며, 실제로 표시된 계산 단계:
    1. 기본 입력값(기본풍속 Vs, 지표면조도구분, 평균높이 H, 지붕폭 최전분 단면 b, 경사각,
       X/Y방향 기본풍, 처마높이(지붕보 간격), 지붕보의 경간).
    2. 지표면조도 계수(KDS 표 5.4-3): K_D 풍향계수, K_zt 지형계수, I_w 중요도계수, C_r
       구조계수, n_Rb 기본진동수.
    3. 순압력계수 C_N(β=12.0° 보간) 및 설계압 풍압 — WL1~WL4 케이스별 C_NW(풍상)·C_NL
       (풍하)·P_W·P_L 표.
    4. MIDAS GEN NX 입력 구역 구분: 1구역(경사 높은 쪽, 검사 높은 부위) / 2구역(보완구역, 검사
       낮은 부위) — 각 구역별로 어떤 WL 케이스의 계산값을 GEN NX 입력값에 대입하는지 정리.
    5. 순골조물하중 — 기둥 설계속도압(q_h × G_pa), 기둥 단면폭 d, 선하중 W(=P_F × d).
  - "물론 계산서는 출력도 가능합니다"라는 자막으로 산정 근거 문서화 기능도 확인.

## 5. 워크플로우

### Step 1 — Apps에서 실행 및 CASE 선택

- GEN NX `Apps > Plug-in > Solar Structure Modeling` 실행.
- "태양광 구조물 CASE를 선택하세요" 화면에서 CASE 1~4 중 실제 해석할 모듈과 같은 형식 선택
  (예: CASE 1 — 단기둥 태양광구조물).

### Step 2 — API 연결 및 재료·단면 선택

- Base URL, API Key, GEN NX 단위(mm) 입력 후 "연결 테스트".
- "GEN NX에서 불러오기" 클릭 → 재료/기둥 단면/지붕보 단면/브레이스 단면/퍼린 단면 드롭다운에
  현재 모델의 정의된 항목이 채워짐. 없으면 GEN NX 네이티브 Material Data/Section Data 창에서
  먼저 정의(SS275 강재, H-Section/Cold Formed Channel 카탈로그에서 B100×100×2.3, LC-100×50×
  20×2.3 등)한 뒤 다시 불러옴.

### Step 3 — 치수·경계조건 입력(모델링에 필요한 정보 기재)

- 기둥 높이(H), 지붕보(경사각 θ, 길이1(RL)·길이2(RR)).
- 브레이스1(각관, TRUSS): 부재 높이(l1), 각도(기둥 기준).
- 브레이스2(우측, TRUSS): 부재 높이(l2), 각도(기둥 기준).
- 퍼린(PIN-PIN): 퍼린 수(최소 2), Y방향 배치(열 수, 열 간격 S).
- 가로브레이스(TRUSS): 하단·상단 높이.
- 경계조건: 기둥 하단 지점(핀(이동 구속, 회전 자유) 등).
- 입력할 때마다 우측 입면도·배면도가 실시간 갱신되어 형태를 확인.

### Step 4 — 하중값 입력

- 면하중 자동 생성: 고정하중(Dead Load), 적재하중(Live Load), 설하중(Snow Load) kN/m² 입력.
- 풍하중 자동 생성: 기본풍속(Vs, 예 30m/s), 지표면조도구분(예 C — 일반 지역), 순골조물하중
  기준 연산 체크, 기둥 단면폭(d, 예 200mm) 입력 → "계산서 출력" 클릭 시 위 5단계 산정 근거
  전체를 확인.

### Step 5 — 모델링 생성

- "모델링 생성" 클릭 → 입력된 정보를 토대로 GEN NX 모델에 절점·요소·경계조건·하중이 자동
  생성됨.
- 결과: Nodes 30, Elements 43(Truss 10, Beam 33), Material 1(SS275), Section 2(B100×100×2.3,
  LC-100×50×20×2.3), Supports 3(Type 1 [111111], 즉 6자유도 완전 고정), Beam End Release 8
  (Type 1 [000111], 즉 모멘트 3방향 해제 — 트러스/핀 접합 브레이스에 적용된 것으로 추정),
  Static Load Case 1(DL, 고정하중), Floor Loads 등이 생성됨.
- 3D 뷰에서 태양광 패널 프레임 형상(기둥·V자형 브레이스·경사 지붕보·퍼린)이 정확히 재현된
  것을 확인.

## 6. 연계 JSON API 엔드포인트

화면에 정확한 API 요청 로그는 노출되지 않았으나, 최종 GEN NX 모델 트리(Nodes/Elements(Truss/
Beam)/Material/Section/Supports/Beam End Release/Static Loads/Floor Loads)로 명확히
매핑된다:

| 기능 | 추정 API | 문서 위치 |
| --- | --- | --- |
| 재료·단면 조회 | `GET /db/MATL`, `GET /db/SECT` | [`04_DB_Properties.md#1-dbmatl`](../../manual/04_DB_Properties.md#1-dbmatl), [`#12-dbsect`](../../manual/04_DB_Properties.md#12-dbsect) |
| 절점·부재(기둥/지붕보/브레이스/퍼린) 생성 | `POST /db/NODE`, `POST /db/ELEM` | [`03_DB_Node_Element.md#1-dbnode`](../../manual/03_DB_Node_Element.md#1-dbnode), [`#2-dbelem`](../../manual/03_DB_Node_Element.md#2-dbelem) |
| 경계조건(기둥 하단 핀 지점) | `POST /db/CONS` | [`05_DB_Boundary.md#1-dbcons--constraint-support`](../../manual/05_DB_Boundary.md#1-dbcons--constraint-support) |
| 부재 단부 해제(브레이스/퍼린 핀 접합) | `POST /db/FRLS` | [`05_DB_Boundary.md#12-dbfrls--beam-end-release`](../../manual/05_DB_Boundary.md#12-dbfrls--beam-end-release) |
| 정적하중케이스(DL/LL/설하중) 생성 | `POST /db/STLD` | [`06_DB_Static_Loads.md#1-dbstld--static-load-cases`](../../manual/06_DB_Static_Loads.md#1-dbstld--static-load-cases) |

- ⚠️ "면하중"(Floor Load) 생성에 사용되는 정확한 엔드포인트(`/db/STLD` 계열의 Floor Load
  Type 또는 별도 엔드포인트인지)는 화면에 노출되지 않아 추정이다.
- KDS 41 12:00:2022 풍하중 계산 자체(순압력계수 C_N, 설계압력 P_W/P_L, 순골조물하중 산정)는
  GEN NX Open API가 제공하는 결과가 아니라 Plug-in이 자체 구현한 계산 로직으로 보인다 —
  #10(RCBeamDeflectionCheck)의 처짐 계산, #16(CraneLoader)의 KDS 41 10 15 계산과 동일하게
  "API로 최소 형상 데이터만 가져오고 전문 하중 계산은 직접 수행 후 절점하중/하중케이스로
  기록"하는 패턴으로 추정된다.

## 7. 입력 데이터 규격

- **CASE 선택**: CASE 1~4 중 하나.
- **치수**: 기둥 높이, 지붕보 경사각·길이(RL/RR), 브레이스1·2 부재 높이·각도, 퍼린 수·Y방향
  열 수·열 간격, 가로브레이스 상하 높이.
- **재료·단면**: 기존 GEN NX 정의 재사용 또는 신규 정의.
- **하중**: 고정·적재·설하중(kN/m²), 풍하중(기본풍속, 지표면조도구분, 기둥 단면폭).

## 8. 출력 / 생성 결과

- GEN NX 모델의 Node/Element(Truss/Beam)/Material/Section/Supports/Beam End Release/Static
  Load Case(DL/LL/Floor Loads)/풍하중 절점하중 전체.
- 풍하중 산정 근거 계산서(출력 가능).

## 9. 제약사항 및 한계

- 4가지 CASE로 정형화된 태양광 구조물 형식만 지원하며, 비정형 배치(예: 곡면 지붕, 비대칭
  브레이스 구성)는 이 Plug-in의 범위를 벗어나는 것으로 보인다.
- Beam End Release가 "Type 1 [000111]"로 일괄 적용된 것으로 관찰되는데, 이것이 모든 브레이스·
  퍼린에 동일하게 적용되는 고정 규칙인지, 아니면 CASE·부재 종류별로 다르게 적용되는지는
  화면상 명확히 확인되지 않았다(⚠️ 미확인).
- 풍하중 계산은 KDS 41 12:00:2022 한 가지 기준만 지원하는 것으로 보이며, 다른 국가·버전
  기준에 대한 지원 여부는 언급되지 않았다.
