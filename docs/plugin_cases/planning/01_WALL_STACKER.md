# WALL STACKER — 기획문서

> **분석 대상:** [영상](../videos/01_WALL_STACKER.mp4)(176초, 4K/30fps, 6초 간격 30프레임 추출·분석) +
> [원문 아티클](../articles/01_WALL_STACKER.md)
> **작성일:** 2026-08-07 · **작성 방식:** 영상 프레임 단위 UI 분석 + 화면 내 API 호출 로그 판독

---

## 1. 개요

구조도면(DXF)을 층별로 입력하면, 벽체 중심선을 자동으로 인식해 GEN NX 해석모델에 **벽체(Wall)
요소와 개구부 인방보(Lintel Beam)를 자동 생성**하는 Plug-in. "층별 도면 입력 → 후보/설정
확인 → Gen NX 생성"의 3단계 마법사(Wizard) 형태로 동작하며, 여러 층의 DXF를 한 번에 등록해
일괄 처리할 수 있다.

## 2. 문제 정의 (해결하려는 페인포인트)

- 구조도면의 벽체 중심선을 GEN NX에 절점·요소로 옮기는 작업은 층수가 많을수록 반복 노동이
  누적된다.
- DXF는 사람이 그린 도면이라 **벽체 교차부에서 선이 정확히 만나지 않거나**, 같은 접합부인데도
  층마다·구간마다 좌표가 미세하게 어긋나 있는 경우가 흔하다. 이를 그대로 절점화하면 절점이
  중복 생성되어 요소가 끊기거나(단절), 불필요한 절점이 늘어나 해석모델 품질이 떨어진다.
- 개구부(창호 등) 위의 인방보는 벽체 모델링과 별도로 챙겨야 하는 항목이라 누락되기 쉽다.

## 3. 목표 사용자

RC 벽식 구조(아파트/주상복합 등)의 초기 해석모델을 만드는 구조 엔지니어. 특히 여러 층의
벽체를 반복적으로 모델링해야 하는 실무자.

## 4. 핵심 컨셉 / 차별점

- **DXF 레이어 기반 자동 인식** — "중심선 레이어"와 "벽체 레이어"만 지정하면 나머지 형상
  판독은 Plug-in이 처리한다(그 외 레이어는 굳이 지우지 않아도 무방).
- **끝점(절점) 자동 보정** — 도면상 미세하게 어긋난 접합부를 허용거리 기준으로 자동 정렬·통합
  하고, 보정 전/후를 시각적으로 비교해 사용자가 승인하는 구조(완전 자동이 아니라 **검토 후
  승인**하는 반자동 방식).
- **인방보 자동 생성 옵션** — 개구부 폭 최소/최대 기준을 두고 조건을 만족하는 개구부에만
  인방보를 자동 배치, 개별 항목을 리스트에서 제외할 수 있다.
- **PLAN 재사용(라이브러리)** — 같은 평면을 여러 층에 매핑할 수 있어(기준층 반복 등) 층마다
  DXF를 새로 준비할 필요가 없다.

## 5. 워크플로우 (영상 분석 기반 3단계 상세)

### Step 1 — 층별 도면 입력 (STEP 1 · DRAWINGS)

| 화면 요소 | 동작 |
| --- | --- |
| AUTO STORY | "생성할 층수"와 "자동 모델링 시작높이"를 입력하고 **"층 목록 생성"** 클릭 → Story 정보 자동 입력. 생성 후 개별 항목 편집 가능 |
| PLAN LIBRARY (PLAN 보관함) | DXF 파일을 드래그앤드롭 또는 파일탐색기로 다중 등록. 등록된 DXF는 카드 형태로 나열(파일명, 등록일시, 개별 삭제 버튼) |
| 적용 범위 일괄 설정 | "적용 범위(시작~종료 층)" + "PLAN 일괄 배정"(등록된 PLAN 중 선택) + "층고 일괄 배정(m)"을 지정 후 **"적용"** → 여러 층에 같은 PLAN·층고를 한 번에 매핑 |
| 층별 테이블 | 층(1층~N층)마다 **층고**와 **PLAN 선택**(드롭다운, 개별 지정 가능)을 표 형태로 확인·수정 |

- 상단 상태바에 진행 단계(1/2/3)가 표시되고, 입력 항목에 **맥동(pulse) 강조 효과**로 다음
  액션을 안내 — 최초 사용자 온보딩을 UI 레벨에서 지원.
- 우측 상단 "모델 연결됨" 인디케이터로 GEN NX 연결 상태를 상시 표시.

### Step 2 — 후보/설정 확인 (STEP 2 · 후보/설정 확인)

**2-1. 층별 레이어 및 추출 조건**

| 파라미터 | 설명 |
| --- | --- |
| 전체 레이어 → 중심선 레이어 / 해당층 벽체 레이어 | DXF의 전체 레이어 목록에서 좌우 화살표로 "중심선 레이어" 1개, "벽체 레이어" 1개를 지정(각 층마다 반복) |
| 허용거리(mm) | 절점 자동 통합 시 "같은 접합부"로 간주할 좌표 오차 허용 범위 (기본 150) |
| 최소길이(mm) | 이보다 짧은 벽체 세그먼트는 무시/병합 대상 (기본 300) |
| 중복배치간격(mm) | 벽체 중복 배치 판정 간격 (기본 250) |
| 끝면보정(mm) | 벽체 끝단 보정 거리 (기본 50) |
| 좌표스케일 | 도면 좌표 단위 환산 계수 (기본 0.001, 즉 mm→m) |
| 두께(m) / 두께 ID / 콘크리트 강도 / 재료 ID(자동) | 해당 층 벽체의 두께·재료 물성. 재료 ID는 두께·강도 조합으로 자동 채번(예: `9000: 24MPa_Wall Stacker`) |
| AUTO LINTEL(개구부 인방보 자동 생성) — ON/OFF 토글 | ON 시 아래 세부 옵션 노출 |
| 최소/최대 개구폭(mm) | 이 범위의 개구부에만 인방보 자동 생성(기본 300~4000) |
| 인방 높이(m) / 보 폭(=벽 두께) | 인방보 단면 치수 |
| 단면 ID / 검출 인방보 개수 | 자동 채번된 단면 ID, 조건을 만족해 검출된 인방보 총 개수(예: 25개) |
| PLAN 미리보기 | 층별 탭(BASE/1층/2층/…)으로 전환하며 추출된 벽체·인방보 라인을 시각 확인. 하단에 BASE 선(59), 보정 개수(3), 승인 대기(0), 검토 항목(116) 등 요약 카운터 표시 |

**2-2. 끝점 보정 (자동 모델링 검토 — 보정)**

- 도면 오버레이 그래프에서 미세하게 어긋난 절점 쌍을 강조 표시(예: "보정1: 3층→2층, 편차거리
  7.5mm").
- 목록에서 각 보정 항목을 **개별 "승인"** 하면 그래프에서 해당 절점이 초록색으로 바뀌며 하나의
  절점으로 통합됨을 시각적으로 확인 가능.
- 상단 탭으로 "곱쳐 보기 3(겹쳐진 것)" / "간발보 검토 25(인방보 검토 25건)" / "검토 초기화"
  전환.

**2-3. 인방보 검토**

- 같은 그래프 위에 인방보 후보를 주황 점선/굵은 빨간 선으로 표시.
- 목록에서 각 인방보 항목(예: "인방1, 1층, 2612mm")을 개별 **"제외"** 처리 가능 — 자동 검출된
  인방보 중 불필요한 것을 사용자가 걸러낼 수 있음.
- 하단에 **"후보 CSV 내보내기"**, **"검토 JSON 저장"** 버튼 — 검토 결과를 외부 파일로
  저장/재사용 가능.

### Step 3 — Gen NX 벽체 생성 (STEP 3 · CREATE)

| 항목 | 내용 |
| --- | --- |
| 실행 | "GEN NX에 벽체 생성" 버튼 1회 클릭으로 전체 층 일괄 생성 |
| 결과 요약 | "벽체 생성 완료!" + 생성된 **노드 수**·**벽체 수**(예: 노드 197개, 벽 109개) 표시 |
| 최근 작업(작업 로그) | 화면에 실제 API 호출 이력이 순서대로 노출됨(아래 6절 참고) |
| 재생성 | "다시 생성" 버튼으로 동일 설정 재실행 가능 |
| 생성데이터 상세보기 | 별도 패널로 생성 상세 내역 확인 가능 |

생성 직후 GEN NX 3D 뷰에 벽체·인방보가 즉시 반영되고, Tree Menu에 `Structures > Nodes 197 /
Elements 134 (Beam 25 + Wall 109)`, `Properties > Material 0 / Section 1 / Thickness 1`이
채워지는 것을 확인. 최종 화면 안내 문구: **"필요시 기둥과 보 부재를 추가하여 해석 모델을
완성합니다"** — 이 Plug-in은 벽체·인방보까지만 책임지고, 기둥·바닥보 등 나머지 부재는 별도
모델링이 필요함을 명시.

## 6. 연계 JSON API 엔드포인트 (영상 내 작업 로그 판독)

Step 3 실행 시 화면에 노출된 실제 로그 순서:

```
GET  db/PJCF   — 자동 연결 확인 성공
     PLAN 4개 일괄 등록
POST db/MATL   — 재료 9000 : 24MPa_Wall Stacker 생성
POST db/THIK   — 두께 200 생성
POST db/SECT   — 인방보 단면 10000 생성
POST db/NODE   — 노드 197개 생성
POST db/ELEM   — WALL 109개 · 인방보 25개 생성
```

`docs/manual` 대응 문서:

- [`/db/PJCF` — Project Information](../../manual/02_DB_Project_Structure.md#1-dbpjcf--project-information) *(연결 상태 확인용 GET)*
- [`/db/MATL` — Material Properties](../../manual/04_DB_Properties.md#1-dbmatl)
- [`/db/THIK` — Thickness](../../manual/04_DB_Properties.md#13-dbthik)
- [`/db/SECT` — Section Properties](../../manual/04_DB_Properties.md#12-dbsect) *(인방보 단면)*
- [`/db/NODE` — Node](../../manual/03_DB_Node_Element.md#1-dbnode)
- [`/db/ELEM` — Element](../../manual/03_DB_Node_Element.md#2-dbelem) *(`TYPE`: Wall용 Plate, 인방보용 Beam으로 추정 — 원문에 정확한 Element Type 문자열은 노출되지 않아 단정하지 않음)*

> ⚠️ 위 매핑은 화면에 노출된 로그 문구(한글 요약)를 근거로 추정한 것이며, 실제 요청 바디의
> 정확한 Key/Value까지는 영상에서 확인되지 않는다. 이 Plug-in을 직접 재현·검증할 때는
> `docs/manual`의 각 엔드포인트 스키마를 기준으로 실제 GEN NX 세션에 대해 별도 검증이
> 필요하다.

## 7. 입력 데이터 규격

- **형식:** DXF (AutoCAD 2023에서 준비하는 장면이 영상에 등장 — 특정 버전 종속은 확인 안 됨)
- **레이어 요구사항:** 해당 층의 "벽체 레이어"와 "중심선 레이어"만 있으면 사용 가능. 그 외
  레이어(치수선, 참조선 등)는 Plug-in에서 조절 가능하므로 미리 정리할 필요 없음.
- **필수 제약:** **각 층 도면의 원점이 일치**해야 한다(영상 내 안내 문구 원문 그대로).
- 하나의 PLAN(DXF)을 여러 층에 재사용 가능(기준층 매핑).

## 8. 출력/생성 결과

- GEN NX 모델에 직접 반영되는 **Node**, **Wall(Plate 계열) Element**, **Lintel Beam
  Element**, 그리고 이에 필요한 **Material / Section(인방보 단면) / Thickness(벽체 두께)**
  속성 일체.
- 검토 단계 산출물: 보정/인방보 후보 **CSV**, 검토 상태 **JSON**(재작업 시 불러오기 용도로
  추정 — 영상에서 "불러오기" 동작 자체는 확인되지 않음).

## 9. 제약사항 및 한계 (영상·문서 근거)

- 벽체·인방보까지만 생성 — **기둥·바닥보 등 나머지 골조는 사용자가 별도로 추가**해야
  완전한 해석모델이 된다(최종 화면 안내 문구).
- 각 층 도면의 원점이 어긋나면 정상 동작하지 않는다.
- 끝점 보정·인방보 생성은 완전 자동이 아니라 **사용자 승인이 필요한 반자동 워크플로**다 —
  즉 무인 배치 처리(batch)에는 적합하지 않고, 검토 단계에서 사람의 개입이 전제된다.
- 원문 아티클(가입/조회수 기준 33·420) 대비 영상만으로는 오차 허용 범위의 권장값 근거,
  인방보 단면 산정 로직의 세부 계산식은 확인되지 않는다 — 실제 기획/개발 시 원 개발자
  확인이 필요.
