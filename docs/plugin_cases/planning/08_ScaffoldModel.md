# ScaffoldModel 기획문서

> 영상(`docs/plugin_cases/videos/08_ScaffoldModel.mp4`, 60fps, 1920×1038, 약 262초)을 9초
> 간격으로 프레임 캡처(총 30장) 후 프레임별 육안 분석 + 하단 자막을 근거로 작성. 원문
> 아티클(`docs/plugin_cases/articles/08_ScaffoldModel.md`)의 4대 기능 설명과 교차 확인함. #7
> ScaleUp과 마찬가지로 GEN NX "My Work"(Apps) 패널에서 실행되는 등록형 Plug-in이며, 단일 대화
> 상자 안에서 모델링부터 하중·해석·Steel Code Check·이미지 저장·검토서 작성까지 전부 처리하는
> 원스톱(one-stop) 구조가 특징.

## 1. 개요

**ScaffoldModel(Scaffold-Mddel)**은 MIDAS GEN NX에서 외줄비계 및 쌍줄비계(건설 현장 가설
비계) 모델 생성부터 하중 재하, 구조해석, Steel Code Check, 결과 이미지 저장 및 비계 구조검토서
작성까지의 전 과정을 자동화한 실무형 도구다.

## 2. 문제 정의

- 외부비계 구조검토는 실무에서 반복적으로 수행되는 정형화된 작업(모델링 → 하중 재하 → 해석 →
  Steel Code Check → 결과 이미지 저장 → 검토서 작성)이지만, 매번 수동으로 진행하면 시간이 오래
  걸린다.
- 특히 풍하중, 방음벽·낙하물방지망 부가하중, 벽연결재 조건 등 비계 특유의 하중 조합을 매번
  다시 구성해야 하는 번거로움이 있다.

## 3. 목표 사용자

- 건설 현장의 외줄/쌍줄 비계 구조검토서를 작성해야 하는 구조 엔지니어.
- 동일한 검토 절차를 여러 현장(프로젝트)에 반복 적용해야 하는 실무자.

## 4. 핵심 컨셉 / 차별점

- **모델링 → 해석 → 검토서까지 하나의 대화 상자에서 끊김 없이 처리**: "모델 생성 → 해석 실행 →
  해석이미지저장 → 검토서 작성" 4개 버튼이 같은 팝업 하단에 순서대로 배치되어, 창을 닫지 않고
  전체 파이프라인을 순차 실행할 수 있다.
- **외줄/쌍줄 비계 형식 전환**: "비계 형식"에서 외줄비계/쌍줄비계 체크박스로 형식을 바꾸면
  입력 필드 구성 자체가 바뀐다(쌍줄비계는 내측/외측 수직재 간격, 장선 길이 등 외줄비계에 없는
  필드가 추가로 노출됨).
- **"새파일에서 생성" vs "기존 데이터 보호" 2가지 실행 모드**: 새파일에서 생성은 새 프로젝트
  기준으로 비계 모델을 생성하는 방식이고, 기존 데이터 보호는 기존 모델 데이터를 유지한 채 비계
  모델을 추가하는 방식 — 이미 다른 구조 모델이 있는 파일에 비계만 덧붙이는 시나리오를 지원.
  기존 데이터 보호 모드로 재실행하면 **새 비계 모델이 기존 모델과 겹치지 않도록 자동으로
  이격되어 생성**되는 것을 시연으로 보여줌(예: 8m 오프셋).
- **부가 하중을 체크박스로 토글**: 방음벽 설치·낙하물방지망 설치를 체크박스로 켜면 해당 하중
  값(방음벽 높이/하중, 낙하 하중) 입력 필드가 나타나고, 이 값들이 자동 생성되는 하중조합
  (1.0D, 1.0D+1.0L, 0.8D+0.52W, 0.8D-0.52W, ENV_ALLOW)에 반영됨.
- **해석 이미지 자동 저장 + 검토서 자동 첨부**: "해석이미지저장" 버튼으로 지정 경로(예:
  `C:\MIDAS\CaptureTest`)에 등각 투상도·하중 다이어그램(풍하중/낙하물방지망 하중/부재력 등)을
  PNG로 저장하고, "검토서 작성" 단계에서 "비계 검토서에 넣을 하중 산정표 이미지를 선택하시겠
  습니까?" 확인 후 저장된 이미지를 자동으로 검토서(HTML)에 첨부.

## 5. 워크플로우

### Step 1 — Apps에서 실행

- GEN NX 우측 `Tree Menu 2 > Works` (My Work 패널)에서 "Scaffold-Mddel" 앱을 검색·선택 → Run.

### Step 2 — 비계 모델링 입력

패널은 5개 그룹으로 구성:

| 그룹 | 필드 | 비고 |
| --- | --- | --- |
| 데이터 생성 방식 | 새파일에서 생성 / 기존 데이터 보호 | 상호 배타적 체크박스 |
| 비계 형식 | 외줄비계 모델링 / 쌍줄비계 모델링 | 선택에 따라 하단 입력 필드 구성이 달라짐 |
| 수평재 및 수직재 | 비계 세로높이, 비계 가로길이, 첫 수평재 높이, 수직재 간격, 수평재 간격 (+쌍줄비계는 내측/외측 수직재 간격, 장선 길이 추가) | mm 단위 |
| 벽연결재 | 시작높이, 가로설치간격, 세로설치간격, 길이 | mm 단위 |
| 하중 | 풍하중 WL(kN/m²), 방음벽 설치(높이/하중 DL), 낙하물방지망 설치(하중 DL), 생성 하중조합 | 체크박스로 부가 하중 on/off |
| 해석 이미지 | 프로젝트명, 이미지 저장경로 | 검토서 표지·첨부에 사용 |

- 영상 예시 값: 비계 세로높이 14000mm, 가로길이 6000mm, 첫 수평재 높이 300mm, 수직재 간격
  @600mm, 수평재 간격 @1500mm, 벽연결재 시작높이 600mm·가로/세로 설치간격 @3000mm·길이
  500mm, 풍하중 WL 0.519kN/m², 방음벽 높이 4m·하중 DL −0.5kN/m², 낙하 하중 DL −1.5kN.

### Step 3 — 모델 생성

- "모델 생성" 클릭 → 하단 실행 로그: "이 단계에서 재료, 단면, 절점, 부재가 생성되고..." → 화면에
  격자형 비계 3D 모델(Node/Element/Section/Material)이 생성됨.
- 이어서 "하중 케이스, 하중 그룹, Floor Load Type, 하중조합이 생성됩니다" → 트리 메뉴에 Static
  Load Case 1(DL: Dead Load)/2(LL: Live Load)/3(WL: Wind Load on Structure)가 자동 생성되고
  각 케이스에 Self Weight, Nodal Loads, Floor Loads가 채워짐.

### Step 4 — 해석 실행 및 Steel Code Check

- "해석 실행" 클릭 → 구조해석 진행.
- 이어서 "Steel Checking" 진행 상태 창(Read or Check Steel Members...) → KDS 41 30:2022 기준
  Start/End Code Checking 로그, Member Checking 250/250 완료.
- 실행 결과 요약이 팝업 하단 텍스트 영역에 자동 기재됨: "모델링 보고 실행 결과 요약 — 모델링
  방식: 새파일에서 생성, 비계 형식: 외줄비계, Steel Code Check → 완료", "모델 생성 요약 — 비계
  세로높이/가로길이/부재 생성, 노드·요소 생성, 벽연결재 boundary 조건 적용됨, Steel Code
  Check 진행됨".

### Step 5 — 해석 이미지 저장

- "해석이미지저장" 버튼 클릭 → 지정 경로(`C:\MIDAS\CaptureTest`)에 `01_iso`, `02_load_wind`,
  `03_load_fall_protection`, `04_load_sound_barrier`, `06_beam_my`(부재력도) 등 여러 시점·
  하중별 PNG 이미지를 자동 캡처·저장.

### Step 6 — 검토서 작성

- "검토서 작성" 클릭 → "비계 검토서에 넣을 하중 산정표 이미지를 선택하시겠습니까?" 확인 모달
  (확인: 이미지 선택 / 취소: 하중산정표 별도검부) → "확인" 선택 시 캡처된 이미지들이 검토서에
  자동 첨부됨.
- 결과물: `비계검토서_00구 00동 00-00_20260728(10).html` — 표지("비 계 검 토 서", 프로젝트명,
  작성일자)와 검토 개요(비계 및 안전시설물 설치(KDS 41 60 10)에 따른 검토, 연직하중·풍하중·
  하중조합 요약 표)를 포함한 HTML 보고서가 다운로드 폴더에 저장되고 브라우저로 바로 열람 가능.

### Step 7 — (반복 시연) 기존 데이터 보호 모드 + 쌍줄비계

- "기존 데이터 보호 방식으로 실행해 보겠습니다" — 데이터 생성 방식을 "기존 데이터 보호"로,
  비계 형식을 "쌍줄비계 모델링"으로 변경해 재실행.
- 쌍줄비계 전용 필드(내측 수직재 간격 @750, 외측 수직재 간격 @1500, 장선 길이(내외경 간)
  @1500) 입력.
- "새 비계 모델이 기존 모델과 겹치지 않도록 이격되어 생성되는 것을 확인할 수 있습니다" —
  기존 외줄비계 모델 옆에 8m 오프셋으로 새 쌍줄비계 모델이 자동 배치됨(Nodes 476/Elements
  931로 증가).
- "모델 생성 후 사용자가 부재 배치나 적용 조건을 확인하고 필요한 부분을 수정한 뒤 GEN NX API를
  활용하여 비계 모델 생성부터... 작업 시간을 크게 단축했습니다" — 자동 생성 후 수동 보정이
  가능한 반자동 워크플로임을 강조하며 마무리.

  화면상 확인되지 않았다.

## 7. 입력 데이터 규격

- **비계 치수**: 비계 세로높이/가로길이(mm), 첫 수평재 높이, 수직재/수평재 간격.
- **벽연결재**: 시작높이, 가로/세로 설치간격, 길이.
- **하중**: 풍하중 WL(kN/m²) 필수, 방음벽·낙하물방지망 하중은 체크박스로 선택 입력.
- **해석 이미지 저장경로**: 로컬 파일 경로(예: `C:\MIDAS\CaptureTest`).

## 8. 출력 / 생성 결과

- GEN NX 모델에 생성된 외줄/쌍줄 비계 구조(Node/Element/Section/Material/Boundary/Load).
- 해석 결과 이미지(PNG, 등각도·하중 다이어그램·부재력도 등).
- "비계 검토서" HTML 보고서(하중 산정표 이미지 첨부 포함).

## 9. 제약사항 및 한계

- "기존 데이터 보호" 모드는 기존 모델과 겹치지 않도록 자동 이격 배치하지만, 정확한 이격
  거리(예: 8m)를 사용자가 직접 지정할 수 있는지는 영상에서 확인되지 않았다(⚠️ 자동 산정으로
  보이나 기준 미확인).
- 자동 생성 후에도 "사용자가 부재 배치나 적용 조건을 확인하고 필요한 부분을 수정"해야 함을
  스스로 명시 — 완전 무검토 자동화가 아니라 초안 생성 도구로 설계됨.
- Steel Code Check 결과가 OK/NG로만 표시된다고 원문에 언급되어 있으나, 영상에서 개별 부재의
  NG 상세 내역(구체적으로 어떤 부재가 어떤 사유로 NG인지)을 보여주는 장면은 포착되지 않았다.
