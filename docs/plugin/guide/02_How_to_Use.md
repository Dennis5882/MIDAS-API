# How to use MIDAS Plug-ins

> **원문:** [How to use MIDAS Plug-ins](https://support.midasuser.com/hc/en-us/articles/35694950947353-How-to-use-MIDAS-Plug-ins)
> **원문 작성:** 2024-07-30 · **원문 최종 편집:** 2024-07-30

---

## 접근 경로

MIDAS Civil NX의 **Apps → API 탭**에 **Plug-in** 메뉴가 있다. 이 메뉴를 열면 Plug-in
창이 팝업으로 뜬다.

## Plug-in 창 구성

| 영역 | 설명 |
| --- | --- |
| Market Place | MIDAS가 제공하는 Plug-in 목록 |
| Saved Plug-ins | Market Place에서 설치한 Plug-in |
| My work | 사용자가 직접 개발한 Plug-in 업로드 영역 |
| Bookmark | 사용자가 즐겨찾기로 지정한 커스텀 폴더. 사용자가 직접 만든 Plug-in도 여기에 등록해 Market에 올릴 수 있음 |
| Available contents | 현재 사용 가능한 Plug-in 콘텐츠를 바로 표시 |

## 개별 Plug-in 실행

원하는 Plug-in(예: "Response Spectrum Generator")을 선택하면, 해당 Plug-in에 대한 설명과
다음 단계를 안내하는 팝업이 뜬다.

| 항목 | 설명 |
| --- | --- |
| Version | Plug-in 버전. 숫자가 클수록 최신 버전 |
| Add | 클릭 시 **Saved Plug-ins** 아래에 저장됨 |
| Video Manual | 영상 형태의 사용법 안내 제공 |
| README | 문서 형태의 사용법 안내 제공 |
| Run | Plug-in 실행 |

**Run** 버튼을 클릭하면 Plug-in이 실행되며, 이후 해당 Plug-in의 기능을 바로 사용할 수 있다.

## 향후 계획 (Marketplace)

원문 작성 시점 기준으로, MIDAS는 사용자가 직접 개발한 Plug-in을 업로드하고 **Marketplace**에서
공유할 수 있는 시스템을 준비 중이라고 안내한다. 국가/조직별로 다른 업무 프로세스를 반영해, 사용자
또는 회사 내부·외부에 Plug-in을 공유할 수 있게 하는 것이 목표다.

> ⚠️ Marketplace 공유 기능은 원문 작성 시점 기준 "준비 중"으로 안내된 내용이다. 실제 제공
> 여부·시점은 정기 점검 시 재확인이 필요하다.
