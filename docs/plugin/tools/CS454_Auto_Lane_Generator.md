# CS454 Auto Lane Generator

> **원문 작성:** 2026-08-18 · **원문 최종 편집:** 2026-08-18

## 개요

CS 454 평가 모델의 교통차선(assessment traffic lane)은 누구나 손으로 만들지만 아무도 좋아하지
않는 작업이다. CS 454는 차선 체계를 하나만 쓰지 않고 세 가지를 한 모델 안에 공존시킨다 —
ALL Model 1의 단일차량용 3.0 m 차선, 대열(convoy)용 2.5 m 차선, 그리고 ALL Model 2용
C/nn(nn은 Equation 5.18로 산출하되 7.5 m 이하 구간은 표의 예외값을 따름) 차선이다. 각
차선은 기준선(reference line)으로부터의 위치, 부재 로컬축 방향에 따라 부호가 바뀌는
편심(eccentricity), MIDAS가 실제 CS 454 적용값의 1/3로 저장하는 윤거(wheel spacing), 그리고
차선이 지나가는 요소마다 하나씩 필요한 Lane Item(긴 교량은 수백 개)까지 요구한다. 여기에
특수차량(special vehicle)이 정상교통과 함께 달리는 조합까지 더해지면 차도 전체를 다시
배치해야 한다. **CS 454 Auto Lane Generator**는 이 산술과 타이핑 작업을 대신한다 — 모델을
읽어 기준선을 도면 위에 설정하고, 선택한 하중에 실제로 필요한 차선을 계산해 평면·단면
양쪽에 차량과 함께 그려 보여준 뒤에야 비로소 기록한다.

## 지원 버전

`MIDAS CIVIL NX 2026 (v2.2)` — Plug-in 버전 `1.0.0`

## 주요 기능

- **세 차선 체계를 분리 관리:** cl 5.8·Table 5.9a의 ALL Model 1(단일차량 3.0 m / 대열 2.5 m)과
  cl 5.18의 ALL Model 2(C/nn)를 서로 다른 이름의 세트로 각각 생성해, 각 이동하중 케이스가
  맞는 세트를 고르게 하고 단면도에서도 색을 구분해 나란히 비교 가능.
- **Equation 5.18과 그 예외를 함께 반영:** Table 5.18의 일반식은 7.5 m 초과 구간에 대한
  것으로, 그 이하 행은 식으로 재현되지 않는 표의 예외다. 표가 적용되는 구간은 표를 조회하고,
  21.9 m를 넘는 구간만 식으로 확장.
- **잔여 영역(remaining area) 조건 처리:** cl 5.16은 잔여 영역에 5 kN/m²를 부여하지만
  cl 5.16.1은 평가 활하중이 7.5톤 이하이면 무재하로 둘 수 있다고 규정 — 이 경우 차선을
  아예 생성하지 않고 근거 조항을 함께 표시.
- **특수차량을 정상교통과 나란히 배치:** CS 458 조합 케이스는 특수차량과 동반 정상교통을
  한 행에 나란히 배치하도록 요구하며(동시 작용), Appendix C3에 따라 정상교통이 차량이
  차지하지 않는 영역을 채우도록 처리.
- **윤거 환산 명시:** Appendix B의 실제 윤거는 축당 1.8 m이지만 MIDAS BS 이동하중 코드는
  저장값을 1/3(0.6)로 요구 — 패널·도면에는 항상 실제 1.8 m를 표시하고 미리보기 표에는 두
  값을 함께 보여줌.
- **Table 5.9a 최소 간격 자동 경고:** 차선폭에서 Appendix B 윤거를 뺀 값이 표의 최소
  인접차량 간격(3.0−1.8=1.2 / 2.5−1.8=0.7)과 정확히 일치함을 이용해, 윤거를 임의로 늘리면
  cl 5.13 위반이 되는지 계산 근거와 함께 경고.
- **보도(footway) 차선 거부 조건 반영:** cl 5.30에 따라 군중 하중 시 재하길이 36 m 초과,
  또는 절대 400 m 초과 구간에서는 보도 차선을 생성하지 않고 근거 조항을 표시.
- **사고차량(accidental vehicle) 하중 조건 판정:** cl 5.27/5.27.1에 따라 유효 방호시설(CD
  377 기준 higher/very high containment)이 없는 중앙분리대·verge·보도를 지지하는 부재에만
  적용 여부를 폭과 방호시설 유무를 함께 물어 판단.
- **기준선을 직접 생성:** 곡선·사교(skew) 교량처럼 측정 기준이 될 단일 부재가 없는 경우,
  선택한 절점을 지나는 기존 보를 채택하거나 10×10 mm 가상 기준보 체인을 새로 생성.
- **기록 전 전량 시각화 및 키 기반 삭제:** 기준선·차선·설정 효과를 기록 전 도면으로 먼저
  표시하며, 삭제는 이름 필터가 전체 삭제로 이어지는 API 특성 때문에 항상 정확한 키 기준으로
  수행.

## 사용 방법

| 단계 | 설명 |
| --- | --- |
| 1 | CIVIL NX에서 교량 모델을 열고 Plug-in 실행 — 연결 정보는 자동 설정되며, Validation Check 카드가 Base URI·MAPI Key 문제를 보고 |
| 2 | **Read model** — 절점·요소·구조군·단면·기존 차선·단위·이동하중 코드를 한 번에 읽음. 이동하중 코드가 없는 모델은 BS로 설정(다른 코드가 이미 설정된 경우 무엇이 사라지는지 안내 없이 임의로 바꾸지 않음) |
| 3 | **Reference line** 선택 — 제안된 선, 요소 범위 입력, 또는 절점 클릭으로 편심 측정 기준선을 지정. 기존 보 재사용 여부·최소 곡률반경을 보고하고 기록 전 도면에 표시 |
| 4 | **Lanes** — ALL Model 1 상황들, ALL Model 2, 단축하중, 보도, 사고하중, CS 458 특수차량, HB 차량, 특수차량 조합 중 필요한 항목만 체크. 체크한 항목이 실제로 쓰는 값만 입력을 요구 |
| 5 | 단면 정의 — CS 454 기준(연석·솟은포장·방호벽 사이, 갓길 포함)의 차도폭과 기준선에서 좌측 연석까지의 오프셋 입력(EN 1991-2 방식과 다름에 주의), 평가 활하중 레벨 설정 |
| 6 | 특수차량 배치 — CS 458 기준 차량폭(자동 산출 불가, 직접 입력 필요)과 조합 내 위치, 정렬 기준 연석 지정 |
| 7 | 도면 확인 — 단면도에 연석면·차선폭·차량 윤거를 축척대로, 평면도에 차선을 표시. 세트별로 색이 구분되어 3.0 m/2.5 m/C/nn 체계를 상호 비교 가능 |
| 8 | 하중 전달 방식 선택(Lane element / Cross beam distribution) 후 **Create** — 전체 세트를 한 번에 기록하고 재조회로 누락 여부 확인. 같은 접두어로 재실행하면 덮어쓰기, 새 접두어는 별도 세트로 추가 |

## 참고/제약사항

- 특수차량 폭은 CS 458에서 가져와야 하는 값으로 Plug-in이 자동 산출할 수 없어 매 실행마다
  직접 입력해야 함.
- 삭제는 이름 필터로 하면 API가 필터를 무시하고 테이블 전체를 비우므로, 항상 재조회한 키
  기준으로만 수행.
- 사교(skew) 각도는 Cross beam distribution을 선택했을 때만 입력 가능(MIDAS 다이얼로그와
  동일 제약).
- Lane element distribution은 차선이 지나는 요소에 직접 하중을 적용하고, Cross beam
  distribution은 횡부재 구조군을 통해 하중을 분배 — 그릴리지 모델이나 Plug-in이 생성한
  기준보(절점이 몇 곳뿐)에는 후자가 필요.

## 결론 (원문)

CS 454 Auto Lane Generator는 평가용 교량 단면을 준비하는 느리고 기계적인 작업 —
Table 5.9a·Equation 5.18이 특정 차도폭에 대해 주는 값을 계산하고, 세 차선 체계를 구분해
유지하고, 특수차량을 동반 교통 옆에 배치하고, 모든 편심의 부호를 맞추고, 기준선의 요소마다
Lane Item을 입력하는 일 — 을 제거한다. 다만 엔지니어링 판단까지 대신하지는 않는다. 차도폭,
기준선 경로, 평가 활하중 레벨, 구조물이 받아야 할 하중, 하중 전달 방식은 모두 사용자가
결정해야 하며, 그 하나하나가 모델에 기록되기 전에 도면·치수·목록으로 먼저 제시된다. cl
5.5.1처럼 CS 454가 다른 문서(CS 458)에 넘기는 사항은 Plug-in도 조용히 답하는 대신 그렇다고
명시한다.
