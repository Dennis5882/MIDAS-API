## 개요

EN 1990 및 그 교량 부속서(Annex A2) 기준 하중조합은 정의는 간단해 보이지만 실제로는
표(ψ 계수표)·그룹·관계식·Annex A2 조합 규칙을 모델에 맞춰 손으로 조립해야 했다. **Eurocode
Load Combinations** Plug-in(버전 2.0.0)은 이 조립 과정을 모델에서 자동으로 구성하도록
개편됐으며, 동시에 이전 버전에서 생성되던 조합식 자체의 오류 여러 건을 항목별로 EN 1990과
대조해 수정했다. 모델은 Plug-in을 실행하고 커밋을 확정하기 전까지는 전혀 바뀌지 않는다.

## 지원 버전

`MIDAS CIVIL NX 2026 (v2.0.0)`

## 주요 기능

### v2.0.0에서 수정된 조합 로직 오류

- **Expression 6.10a의 ψ₀ 미적용 수정:** EN 1990 요구대로 주도(leading) 변동작용에 ψ₀를
  적용하도록 수정 — 이전에는 저감 없이 적용되어 ξ 기본값 1.0에서 6.10b와 완전히 중복되는
  결과를 냈음.
- **ψ 계수를 교량용 값으로 교체:** 기존에는 건물용 Table A1.1 값(교통 0.7/0.5/0.3)이
  적용되고 있었으나, Annex A2 값으로 교체 — 교통의 ψ₂가 0이 되어 준영구·지진·우발 조합에서
  교통하중이 자동으로 빠지게 됨.
- **이동하중 케이스 중복 조합 방지:** MIDAS 이동하중 케이스는 그 자체가 envelope이므로 두
  개를 한 조합에 더하면 동시에 발생하지 않는 차량 위치를 합산하고 교통을 이중 계상하게 됨 —
  EN 1991-2가 요구하는 대로 한 조합에는 교통군(traffic group) 하나만 허용.
- **제동·원심·가속력 저감 적용:** 이전에는 교통이 주도작용이 아닌 경우에도 항상 전체값이
  적용됐으나, 다른 변동작용과 동일하게 ψ₀·ψ₁·ψ₂를 적용하도록 수정.
- **침하(settlement)를 영구작용 계수로 처리:** 극한상태 조합에서 1.0으로 적용되던 것을
  γG로 수정 — 이번 릴리스의 수정 중 유일하게 결과를 더 불리하게 만드는 변경.
- **생성 불가 조합을 누락 대신 보고:** 이동하중에 매핑된 frequent 케이스가 없으면 해당
  reduced form이 필요한 조합이 전부 조용히 사라졌으나, 이제 미리보기에 사유를 표시.

### v2.0.0 신규 기능

- **교량 유형에 따른 ψ 표 자동 선택:** 도로교(Table A2.1)·보도교(A2.2)·철도교(A2.3)를
  구분 — 철도 모델은 이동하중 정의에서 자동 인식하지만, 보도교는 MIDAS 안에서 도로 모델과
  구분되지 않아 별도 선택 필요.
- **그룹·관계식 자동 구성:** 모델을 읽는 즉시 매핑된 하중 타입으로부터 그룹·관계식을
  구성(이전에는 생성 전에 수동 지정이 선행돼야 했음). 이미 수동으로 만든 그룹은 덮어쓰지
  않음.
- **Annex A2 교차 카테고리 규칙 자동 반영:** 적설과 교통을 조합하지 않아도 되는 규칙, 풍하중과
  온도하중을 조합하지 않아도 되는 규칙(철도교는 Annex A2에 해당 규칙이 없어 제외)을
  cross-category constraint로 생성. 두 규칙 모두 국가결정변수(NDP)이므로 검토용으로 별도
  보고.
- **이름 기반 하중 케이스 자동 매핑:** MIDAS 타입으로 식별되지 않는 사용자 정의 하중은
  이름이 모호하지 않은 경우 이름으로 매핑하고 추론 목록을 별도 표시(MIDAS 선언 타입이
  있으면 항상 우선).
- **Envelope 서브조합으로 행 수 축소:** 카테고리 내 상호 배타 대안들을 하나의 Envelope
  서브조합으로 묶어 같은 계수로 참조 가능 — 설계 envelope는 바뀌지 않으면서 행 수만 감소.
- **읽기 쉬운 조합명:** `610B_TRA001_14` 형태 대신 `ULS610b-Traf-14`처럼 식·주도작용을
  드러내는 이름을 사용하고, 이전에는 비어 있던 description 열에 해당 식·영구하중 변형 등을
  문장으로 기재.

## 성능 개선

- 모델을 한 번의 요청 배치로 읽도록 변경 — 테스트 환경(요청당 300 ms) 기준 읽기 시간이
  2.18초에서 0.32초로 단축.
- 4개 식(6.10a·6.10b·characteristic·quasi-permanent)이 변동작용 없는 동일 조합을 각각
  중복 생성하던 것을 하나로 통합.
- Envelope 케이스를 식마다 반복 생성하지 않고 공유.

## 검증

원문에 따르면 released 패키지에서 추출한 엔진을 대상으로 9개 스위트·175건의 자동화된
어서션이 모두 통과했으며, 6.10/6.10a/6.10b/characteristic/frequent/quasi-permanent/6.11(사고)/
6.12(지진) 각 식을 합성 교량 모델의 손계산값과 대조 검증했다고 명시되어 있다. Envelope
옵션은 결합 해제 후 재계산과 비교해 검증(테스트 모델에서 297개 조합이 87개+Envelope 6개로
축소, 누락·오생성 없음).

## 참고/제약사항

- **커밋 경로 자체는 실제 모델에 검증되지 않음** — 조합 생성 로직은 검증됐으나, Envelope
  서브조합을 기존 기능과 같은 iTYPE·`ANAL=CB` 형식으로 기록하는 부분은 이번 릴리스에서 실제
  MIDAS 모델에 대해 실행 검증되지 않았음(원문 명시).
- Envelope는 General Load Combination 테이블에서만 지원되며, 설계용(Design) 테이블에
  커밋을 시도하면 명시적 오류로 거부됨.
- 6.10b의 ξ는 1.0으로 고정되고 영구하중 계수 세트는 하나만 사용 — 별도 γG 값을 쓰는 평형
  검토는 별도 실행 필요.
- 이동하중의 ψ₀·ψ₁은 동일하게 처리 — gr1a와 주요 철도군에는 정확하지만 그 외에는 안전측
  근사.
- Eurocode 이동하중 케이스만 인식되며, 일반 MIDAS 이동하중 케이스를 쓰는 모델은 교통하중이
  전혀 반영되지 않음.
- 피로 조합은 생성하지 않음.
- 자동 생성된 세트이므로, 커밋 전 미리보기와 근거(ledger)를 검토할 것을 원문이 권고.

## 사용 방법

원문이 GUI 워크스루가 아닌 릴리스 노트 형식으로 작성되어 있어, 화면 단계별 사용법은 이
문서에 싣지 않았다. 실제 사용 절차가 필요하면 원문 링크에서 직접 최신 화면을 확인할 것.
