# Seismic Hazard Map

> **원문:** [Seismic hazard map](https://support.midasuser.com/hc/en-us/articles/35658068066841-Seismic-Hazard-Map)
> **원문 작성:** 2024-07-29 · **원문 최종 편집:** 2025-08-01

---

## 개요

National Seismic Hazard Map Plugin은 대한민국 행정안전부가 지진 설계기준 **KDS 17 10
00:2024**에 따라 지정한 지진구역지도(Seismic Hazard Map)를 활용해, 다양한 재현주기 기준으로
특정 부지의 지진위험도를 확인한다.

- KDS 17 10 00:2024 지진 설계기준 검증.
- 다양한 재현주기(50, 100, 200, 500, 1000, 2400, 4800년)에 대한 지진위험도 확인.
- 주소 또는 위도/경도 입력으로 지진위험도 조회.

## 지원 버전

- `MIDAS GEN NX 2026 (v1.1) KR`
- 적용 기준: Korean Standard (KDS)

## 주요 기능

KDS 17 10 00:2024 4.2.1.1(4)에 따르면, 행정안전부 장관이 승인한 국가지진위험지도를 특정
부지의 지진위험(지진재해) 정밀 평가에 사용할 수 있다. 현재 공식 지진위험지도는 2013년에
발간된 "국가지진위험지도"인데, 대표 지역의 데이터 값을 직접 조회할 수 없어 사용자가 이미지의
추정 지점을 분석하는 데 노력을 들이거나 때때로 잘못된 데이터를 입력해 지진 설계 오류로
이어지곤 했다.

- 빠르고 정확한 지진위험 정보 제공.
- 다양한 재현주기에 따른 지진위험 조회 가능.
- 주소 또는 위도/경도 입력으로 사용 편의성 향상.

이 Plug-in은 주소 또는 위도/경도를 기준으로 공식 지도의 데이터 값을 선형 보간해 더 정확한
결과를 제공하지만, 값은 여전히 추정치다.

## 사용 방법

| 단계 | 설명 |
| --- | --- |
| 1. 설계기준 확인 | Plug-in을 실행하고 지진 설계기준 KDS 17 10 00:2024 확인 |
| 2. 재현주기 설정 | 재현주기 설정(예: 2400년) |
| 3. 대상 주소 입력 | 라디오 버튼으로 전환해 주소(By Address) 또는 위도/경도(By Latitude/Longitude) 입력 |
| 4. Search 클릭 | 조회 실행 |
| 5. 결과 확인 | 입력한 주소의 지진위험 결과 확인 |

## 참고/제약사항

KDS 41 17 00: 2022 3.2절에 따르면, 2400년 재현주기에 해당하는 지진구역계수를 적용할 때
국가지진위험지도상 2400년 재현주기의 유효지반가속도(S)는 지진구역계수에 위험도계수를 곱해
계산한다. 계산된 S값과 이 S값의 80% 중 더 큰 값을 유효지반가속도로 사용한다.

설계스펙트럼가속도 계산 시, 유효지반가속도(S)는 KDS 17 10 00의 Table 4.2-3에 제시된
2400년 재현주기 위험도계수(I) 2.0을 지진구역계수(Z)에 곱하거나, Figure 3.2-1의
국가지진위험지도를 이용해 결정할 수 있다. 다만 국가지진위험지도로 결정한 S(유효지반가속도)는
지진구역계수와 위험도계수를 곱해 얻은 S값의 80%보다 작아서는 안 된다.

## 결론 (원문)

이 가이드를 통해 Seismic Hazard Map Plug-in을 활용해 다양한 재현주기 기준으로 특정 부지의
지진위험을 효과적으로 확인할 수 있어, 지진위험 평가의 정밀도와 효율을 모두 높일 수 있다.
