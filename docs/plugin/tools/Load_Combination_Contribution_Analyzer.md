# Load Combination Contribution Analyzer

> **원문:** [Load Combination Contribution Analyzer](https://support.midasuser.com/hc/ko/articles/61258768334233-Load-Combination-Contribution-Analyzer)
> **원문 작성:** 2026-08-18 · **원문 최종 편집:** 2026-08-18

---

## 개요

조합(combination) 결과는 답은 알려주지만 그 답이 어디서 왔는지는 알려주지 않는다. 거더
모멘트가 8개 하중 케이스로 이뤄진 조합에 의해 지배될 때, 실제 계산서에서 중요한 질문은
어느 케이스가 결과의 어느 부분을 만들었는지 — 설계가 교통 envelope에 지배되는지 온도항에
지배되는지, 그리고 얼마나 — 이다.

손으로 답하려면 구성 케이스를 전부 다시 돌려 표로 정리하고 계수를 적용한 뒤 산술이 맞아
떨어지는지 확인해야 한다. **Load Combination Contribution Analyzer**는 이를 직접 계산한다
— 모델에서 조합을 읽어 중첩된 서브조합까지 모두 풀어낸 뒤, 모든 출력 위치에서 구성 하중
케이스 각각의 부호 있는 기여도(signed contribution)를 계산하고, 그 기여도들을 다시 합쳐
CIVIL NX가 실제로 보고하는 값과 대조 검증한 뒤에야 결과를 표시한다.

## 지원 버전

`MIDAS CIVIL NX 2026 (v1.0.0)`

## 주요 기능

- **표본이 아닌 전체 위치:** Beam·Truss·Plate·Plane Stress·Plane Strain·Axisymmetric·
  Solid·Link 결과를 요소·부위(part)·성분(component) 단위로, 로컬·글로벌 두 축 모두 지원되는
  범위에서 전부 분해.
- **매번 CIVIL NX와 대조 검증:** 각 분해 결과를 다시 합산해 같은 조합·같은 위치에 대해
  모델이 실제로 보고하는 값과 같은 요청 배치 안에서 비교 — 허용오차를 넘는 불일치가 있으면
  실행을 중단하며 이를 끌 수 있는 옵션이 없음.
- **표시 정밀도가 아닌 전체 정밀도 요청:** 모델 표시 형식(힘의 경우 소수점 2자리)이 아닌
  유효숫자 9자리로 결과를 요청 — 8개 항으로 구성된 실제 조합에서 재합산 오차가 5e-3에서
  1.4e-7로 줄어들어야 자체 검증이 의미를 가짐.
- **중첩 조합을 올바르게 해석:** 여러 경로로 도달 가능한 하중 케이스는 단일 조회가 아니라
  경로별 계수 곱의 합으로 유효 계수를 산정 — 직접 포함되면서 동시에 서브조합 안에도 있는
  케이스가 한 번만, 정확히 반영됨.
- **Envelope는 선택으로, 지분으로 다루지 않음:** 지배 케이스(governing case)를 요소·부위·
  성분·부호마다 개별적으로 판정해 결과 항목별로 보고 — 부재를 따라가며 실제로 바뀌므로
  평균화하거나 뭉뚱그리지 않음.
- **MIDAS 방식 그대로의 선택 기준:** 구조군·경계군·단면·두께·재료·요소타입 기준으로 선택
  가능하며 각각 요소 개수와 함께 표시, 기준별 체크 상태를 기억해 조합하고 직접 입력한 요소
  번호는 그 위에 합집합으로 추가.
- **불가능한 경우는 추측 대신 거부:** 비선형·좌굴해석(pushover), 크리프·건조수축, 텐던 1차·
  2차 효과, 시간이력 결과, von Mises·주응력 같은 파생량은 하중 케이스에 선형적이지 않으므로
  사유와 함께 명시적으로 거부.
- **계산서용 산출:** 라이트/다크 테마, 자릿수가 맞춰진 숫자 표시, 기여도와 지배맵(governing
  map)의 CSV 내보내기 지원.

## 사용 방법

| 단계 | 설명 |
| --- | --- |
| 1 | 해석이 완료된 모델을 CIVIL NX에서 열고 Plug-in 실행 — MAPI Key가 확인되는 즉시 조합·요소·선택세트·시공단계 목록 로딩 시작 |
| 2 | **Combination**에서 조합 선택 — 모델에 정의된 모든 LCOM 테이블 항목이 표시되며, 하단 **Combination tree**에서 어떻게 풀리는지, envelope 값(max/min 쌍)인지 확인 |
| 3 | 결과 테이블 선택 — Beam·Truss·Plate·Plane Stress·Plane Strain·Axisymmetric·Solid·Link 중 힘 또는 응력, 로컬 또는 글로벌 축. 선택에 따라 요소 타입·표시 성분·선택 가능 요소가 자동으로 필터링됨 |
| 4 | **Select elements by**에서 구조군·경계군·단면·두께·재료·요소타입 기준으로 세트 선택 — 선택한 결과 테이블이 다룰 수 없는 타입의 세트 멤버는 조용히 누락되지 않고 건너뛰며 개수로 표시 |
| 5 | 필요 시 **Elements**에 `700-760, 1200, 1310-1315` 같은 범위로 개별 요소 번호 추가 입력(체크된 세트에 합집합으로 추가) |
| 6 | 분해할 성분 체크 — 선택한 결과 테이블에 맞춰 목록이 바뀌며 합리적인 기본값이 이미 선택돼 있음 |
| 7 | 시공단계 결과일 때만 **Stage:step**을 `CS3:002(last)` 형식으로 입력(사후단계 결과는 비워둠) — 단계가 맞지 않으면 임의로 추정하지 않고 거부 |
| 8 | **Run decomposition** 실행 — 모든 구성 케이스를 요소 범위에 대해 최소한의 요청으로 배치 처리하며, 결과가 표시되기 전에 자체 검증부터 수행 |
| 9 | **Results** 탭에서 Element·Part·Component·Sense 필터로 위치 선택 — 각 케이스의 계수·원시 결과값·부호 있는 기여도·전체(gross) 대비 지분·순(net) 대비 지분과 함께 net·gross·상쇄율(cancellation ratio)·CIVIL NX 보고값을 확인 |
| 10 | **Charts** 탭에서 동일 결과를 공유 0축의 부호 있는 막대그래프, 또는 gross 지분 기준 파이차트로 확인(상쇄가 큰 경우 파이는 비율이 아닌 상대적 영향으로 표기) |
| 11 | envelope 조합에서는 **Governing map**을 열어 요소·부위·성분·부호별 지배 케이스 확인 |
| 12 | **Results** 또는 **Governing map** 탭에서 CSV 내보내기 — 단위·API가 반환한 정밀도·조합 트리 정보가 함께 포함돼 표 단독으로도 해석 가능 |

## 참고/제약사항

- 비선형·좌굴해석(pushover), 크리프·건조수축, 텐던 1차/2차 효과, 시간이력 결과, von Mises·
  주응력 등 파생량은 하중 케이스에 대해 선형이 아니므로 분해를 거부.
- 재합산 결과가 CIVIL NX 보고값과 허용오차를 넘어 다르면 결과를 표시하지 않고 실행을
  중단하며, 이를 우회하는 옵션은 없음.
- 시공단계 결과 조회 시 `Stage:step` 형식이 맞지 않으면 임의로 추정하지 않고 거부.

## 결론 (원문)

Load Combination Contribution Analyzer는 조합 결과만으로는 답할 수 없는 질문 — 어느 하중
케이스가 실제로 설계를 지배하며 얼마나 그러한지 — 에 답한다. 수작업 재실행과 표 정리를
없애고, CIVIL NX가 실제로 처리하는 방식 그대로 중첩 조합과 envelope를 풀어내며, 의미 없는
기여도가 나올 경우에는 값을 인쇄하는 대신 거부한다. 표시되는 모든 숫자는 자기 구성요소로부터
재구성되어 모델과 대조 검증을 거친 뒤에만 나타나며, 이것이 이 결과를 계산서에 실을 수 있게
만드는 이유다.
