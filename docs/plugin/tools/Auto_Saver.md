# Auto Saver

> **원문:** [Auto Saver](https://support.midasuser.com/hc/en-us/articles/35661003551385-Auto-Saver)
> **원문 작성:** 2024-07-29 · **원문 최종 편집:** 2025-08-01

---

## 개요

작업 중인 모델을 설정한 시간 간격마다 자동으로 저장하는 Plug-in이다. 모델링 파일에 대한
자동 저장 기능을 제공한다.

## 지원 버전

`MIDAS CIVIL NX 2024 (v1.1) US`

## 주요 기능

- **저장 간격 커스터마이즈:** 분 또는 시간 단위로 사용자가 정의한 간격마다 모델을 저장해,
  작업을 중단시키지 않으면서 중요 파일 데이터 손실을 방지한다.
- **데이터 손실 방지:** 정기적인 저장으로 최신 백업 상태를 유지해 데이터 손실을 방지한다.

## 사용 방법

| 필드 | 설명 | 옵션·기본값 |
| --- | --- | --- |
| 저장 간격(분) | AutoSaver Plug-in을 활성화하고 저장 간격을 분 단위로 설정 | 기본값 `5분` |
| Auto Save 토글 | 활성화하면 설정한 간격마다 모델링 파일을 자동 저장 | — |
| OK | 클릭하면 설정한 대로 모델 파일이 저장됨 | — |

## 결론 (원문)

Auto Saver Plug-in은 일정 간격으로 변경사항을 자동 저장해 프로젝트를 보호·관리한다. 모델이
자주 갱신되어야 하는 환경에서 특히 유용하며, 작업이 중단 없이 지속적으로 보존되도록 한다.
