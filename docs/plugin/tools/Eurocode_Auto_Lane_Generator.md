# Eurocode Auto Lane Generator

> **원문 작성:** 2026-08-18 · **원문 최종 편집:** 2026-08-18

---

## 개요

교통차선은 EN 1991-2 모델에서 누구나 손으로 만들지만 아무도 좋아하지 않는 작업이다.
Table 4.1이 차도폭에 따라 몇 개의 명목차선(notional lane)을 몇 m 폭으로 둘지 결정하는데,
그 답은 5.4 m~6.0 m 사이에서 두 번 바뀐다. 각 차선은 기준선으로부터의 위치, 부재 로컬축
방향에 따라 부호가 바뀌는 편심, MIDAS 기본값이 1.8 m이지만 EN 1991-2 Figure 4.2b는 2.0 m를
요구하는 윤거, 그리고 차선이 지나는 요소마다 하나씩 필요한 Lane Item(긴 교량은 수백 개)을
요구한다. 곡선·사교(skew) 교량에는 측정 기준이 될 단일 부재가 없는 경우가 많아 기준선을
새로 만들어야 한다. **Eurocode Auto Lane Generator**는 이 산술과 타이핑 작업을 대신한다 —
모델을 읽어 기준선을 도면 위에 설정하고, 선택한 하중군(load group)에 실제로 필요한 차선을
계산해 평면·단면 양쪽에 차량과 함께 그려 보여준 뒤에야 비로소 기록한다.

## 지원 버전

`MIDAS CIVIL NX 2026 (v2.2)` — Plug-in 버전 `1.0.0`

## 주요 기능

- **Table 4.1을 경계값까지 정확히 적용:** 차도폭에 따른 차선 수·폭 결정 시 5.4 m 등
  경계값을 근사가 아닌 정확한 기준으로 처리 — 5.399 m는 3.0 m 차선 1개+잔여영역, 5.4 m는
  2.7 m 차선 2개로 완전히 다른 결과가 되며 임의로 반올림하지 않음.
- **기준선을 직접 생성:** 곡선·사교 교량처럼 측정 기준이 될 단일 부재가 없는 경우, 선택한
  절점을 지나는 기존 보를 채택하거나 10×10 mm 가상 기준보 체인을 새로 생성.
- **윤거를 코드 기준으로:** MIDAS 다이얼로그 기본값 1.8 m는 다른 코드의 값이며, EN 1991-2
  Figure 4.2b가 요구하는 tandem system 윤거 2.0 m를 적용하고, 차선이 좁아 두 윤하중을 모두
  실을 수 없을 때만 축소하며 그 사실을 표시.
- **하중군 또는 개별 하중모델 선택 가능:** EN 1991-2 Table 4.4a의 하중군(gr1a·gr1b·gr3·gr4·
  gr5)을 기본 경로로 쓰되, 개별 검토 시 Load Model 1~4와 보도하중을 따로 선택 가능 — 둘 다
  같은 차선 집합으로 귀결.
- **도로·피로·철도까지 EN 1991-2 전체 커버:** Section 4 도로교통뿐 아니라 cl 4.6의
  피로하중모델, Section 6의 철도하중(궤간 1.435 m 기준 트랙당 1개 차선)까지 처리.
- **철도 편심을 의도적으로 미기재:** cl 6.3.5가 요구하는 궤간/18(표준궤 0.080 m) 편심은
  화면에 표시만 하고 차선에는 쓰지 않음 — MIDAS가 이를 차량(vehicle) 쪽에서 이미 반영하므로
  중복 적용을 방지.
- **편심 부호를 실측으로 확정:** ECC 양수 방향이 요소 로컬 −y축을 따른다는 사실을 실제 모델에
  손으로 만든 차선과 대조해 확정(추정이 아님) — 이 값이 틀리면 모델의 모든 차선이 함께
  틀어짐.
- **기록 전 전량 시각화 및 키 기반 삭제:** 기준선·차선·설정 효과를 기록 전 도면으로 먼저
  표시하며, 삭제는 이름 필터가 전체 삭제로 이어지는 API 특성 때문에 항상 정확한 키 기준으로
  수행.

## 사용 방법

| 단계 | 설명 |
| --- | --- |
| 1 | CIVIL NX에서 교량 모델을 열고 Plug-in 실행 — 연결 정보는 자동 설정되며, Validation Check 카드가 Base URI·MAPI Key 문제를 보고 |
| 2 | **Read model** — 절점·요소·구조군·단면·기존 차선·단위·이동하중 코드를 한 번에 읽음. 이동하중 코드가 없으면 여기서 EUROCODE로 설정 가능하며, 길이 단위가 m가 아니면 별도로 안내(차선폭·편심은 m로 입력) |
| 3 | **Reference line** 선택 — 제안된 선, 요소 범위 입력, 또는 절점 클릭으로 편심 측정 기준선을 지정. 기존 보 재사용 여부·최소 곡률반경을 보고하고 기록 전 도면에 표시 |
| 4 | 필요 시 기준보 생성 — 10×10 mm 단면, 절점·보, 그리고 이후 재조회·삭제를 위한 구조군을 함께 생성 |
| 5 | 단면 정의 및 하중군 선택 — 적용할 EN 1991-2 항목을 체크한 뒤 실제 검토할 하중군을 체크. 연석 사이 차도폭, 기준선에서 좌측 연석까지 오프셋, verge·보도 폭 입력(체크한 하중군이 실제로 쓰는 값만 요구) |
| 6 | 도면 확인 — 단면도에 연석면·차선폭·차량 윤거를 축척대로, 평면도에 차선을 표시. 행을 hover하면 해당 차선이 도면에서 치수와 함께 강조됨 |
| 7 | 하중 전달 방식 선택(Lane element / Cross beam distribution) 후 **Create** — 전체 세트를 한 번에 기록하고 재조회로 누락 여부 확인. 같은 접두어로 재실행하면 덮어쓰기, 새 접두어는 별도 세트로 추가 |

## 참고/제약사항

- 삭제는 이름 필터로 하면 API가 필터를 무시하고 테이블 전체를 비우므로, 항상 재조회한 키
  기준으로만 수행.
- 사교(skew) 각도는 Cross beam distribution을 선택했을 때만 입력 가능(MIDAS 다이얼로그와
  동일 제약) — 이미 입력한 각도는 분배 방식을 바꿔도 유지됨.
- Lane element distribution은 차선이 지나는 요소에 직접 하중을 적용하고, Cross beam
  distribution은 횡부재 구조군을 통해 하중을 분배 — 그릴리지 모델이나 Plug-in이 생성한
  기준보(절점이 몇 곳뿐)에는 후자가 필요.
- 철도 편심(궤간/18)은 차선이 아닌 차량 쪽에 이미 반영되어 있어, 화면 표시값을 차선
  편심으로 별도 입력하면 이중 적용이 됨.

## 결론 (원문)

Eurocode Auto Lane Generator는 Eurocode 기반 이동하중 해석을 위한 교량 단면을 준비하는
느리고 기계적인 작업 — Table 4.1이 특정 차도폭에 대해 주는 값을 계산하고, 차선을 어디에
배치할지 정하고, 모든 편심의 부호를 맞추고, 기준선의 요소마다 Lane Item을 입력하는 일 —
을 제거한다. 다만 엔지니어링 판단까지 대신하지는 않는다. 차도폭, 기준선 경로, 구조물이
받아야 할 하중군, 하중 전달 방식은 모두 사용자가 결정해야 하며, 그 하나하나가 모델에
기록되기 전에 도면·치수·목록으로 먼저 제시된다.
