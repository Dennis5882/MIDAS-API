MIDAS Gen NX MAPI — Auto Save Before Analysis

KO해석 실행 전 파일 자동 저장 패턴  |  ENAuto-save pattern before running structural analysis

Overview

KO  MIDAS Gen NX의 MAPI는 해석(POST /doc/anal)을 실행하기 전에 반드시 파일을 먼저 저장(POST /doc/saveas)해야 합니다. 저장 없이 해석하면 Gen NX가 저장 다이얼로그를 띄워 자동화가 중단됩니다.

이 예제는 GET /mapikey/verify로 연결 상태를 먼저 확인한 뒤, 호출자가 지정한 저장 폴더(또는 C:/Temp 폴백)로 파일명을 조립하고, POST /doc/saveas → POST /doc/anal 순서로 실행하는 전체 흐름을 보여줍니다.

⚠️ 로그인 이메일 계정과 PC의 실제 Windows 계정명이 다를 수 있어, 이메일에서 사용자 폴더를 추정하는 방식(C:/Users/{이메일 앞부분}/...)은 신뢰할 수 없습니다 — 저장 폴더는 호출자가 실제 존재하는 경로를 직접 지정하세요.
EN  MIDAS Gen NX MAPI requires saving the file (POST /doc/saveas) before running analysis (POST /doc/anal). Without saving first, Gen NX shows a save dialog that interrupts automation.

This example first checks the connection via GET /mapikey/verify, then builds the file name inside a caller-provided save folder (or a C:/Temp fallback), then runs POST /doc/saveas → POST /doc/anal in the correct order.

⚠️ The login email account and the PC's actual Windows account name can differ, so guessing the user folder from the email (C:/Users/{email local-part}/...) is unreliable — always pass a real, existing folder as the save directory yourself.

Flow / 동작 흐름

1GET /mapikey/verify → confirm connection (j.user is for display only, not for the path)
↓
2build path from caller-provided saveDir (fallback C:/Temp) → {saveDir}/gen_rc_temp_1234567.mgbx
↓
3POST /doc/saveas  { Argument: "<path>" }
↓
4POST /doc/anal    {}

Why Order Matters / 순서가 중요한 이유

⚠️ KO  /doc/anal을 /doc/saveas 보다 먼저 호출하면 Gen NX가 "저장하시겠습니까?" 다이얼로그를 표시하고 응답을 기다립니다. MAPI 호출은 타임아웃 또는 에러 없이 무한 대기 상태가 될 수 있습니다.

⚠️ EN  Calling /doc/anal before /doc/saveas causes Gen NX to show a "Do you want to save?" dialog and wait for user input. The MAPI call may hang indefinitely without a timeout or error.

Save Folder Must Already Exist / 저장 폴더는 미리 존재해야 함

⚠️ KO  /doc/SAVEAS의 공식 문서(Save As ↗)엔 존재하지 않는 폴더로 저장을 시도했을 때의 동작이 명시돼 있지 않지만, **실제 MAPI 호출로 확인했습니다**(2026-08-31): 폴더가 없으면 Gen NX가 "◯◯에 잘못된 경로가 있습니다" 에러 다이얼로그를 띄우고, MAPI 호출은 그 다이얼로그가 응답을 기다리는 동안 타임아웃됩니다 (자동 생성되지 않음). 폴더를 미리 만들어두면 200 OK로 정상 저장됩니다. C:/Temp도 Windows 기본 폴더가 아니므로, 저장 전에 해당 폴더가 실제로 있는지 직접 확인/생성하세요.

⚠️ EN  The official Save As doc for /doc/SAVEAS does not state what happens if the target folder doesn't exist, but this was **verified with a live MAPI call** (2026-08-31): if the folder is missing, Gen NX shows a "there is an invalid path in ◯◯" error dialog, and the MAPI call times out while that dialog waits for a response (the folder is NOT auto-created). Creating the folder beforehand results in a normal 200 OK save. C:/Temp is not a default Windows folder either, so verify/create it yourself before saving.

Unit Setting Before Build / 단위계 선제 설정

⚠️ KO  모델을 만들기 전(PUT /db/node 호출 전)에 반드시 단위계를 설정하세요. Gen NX가 kN/m 등 다른 단위로 열려 있으면 좌표 7000(mm 의도)이 7000 m로 해석되어 해석 결과에 이상 변위 경고가 발생합니다.

⚠️ EN  Always set the unit system before creating model entities (PUT /db/node). If Gen NX is open in a different unit (e.g. kN/m), the coordinate 7000 (intended as mm) is interpreted as 7000 m, causing abnormal displacement warnings.

Code / 코드

/**
 * KO: Base URL에서 /gen, /civil 경로를 제거해 루트 URL 반환
 *     /mapikey/verify 는 루트(포트 바로 뒤)에 위치합니다.
 * EN: Strip /gen or /civil suffix to get the root URL.
 *     /mapikey/verify lives at the root, not under /gen or /civil.
 */
function mapiRoot(base) {
  return base.replace(/\/(gen|civil)\/?$/i, '');
}

/**
 * KO: 연결 확인 및 로그인 사용자 이메일 반환
 *     j.user 에 이메일 전체가 담깁니다 (예: "john@midasit.com")
 * EN: Verify connection and return the logged-in user's email.
 *     j.user contains the full email (e.g. "john@midasit.com")
 */
async function verifyConn(base, key) {
  const res = await fetch(`${mapiRoot(base)}/mapikey/verify`, {
    headers: { 'MAPI-Key': key }
  });
  let j = {};
  try { j = await res.json(); } catch (e) {}
  return { ok: res.ok, j };
}

/**
 * KO: 저장 경로 결정
 *     1순위: saveDir 인자로 명시된 폴더 (권장 — 항상 정확함)
 *     2순위: C:/Temp  (saveDir 미지정 시 고정 폴백 — 이 폴더도 미리 존재해야 함, 자동 생성 안 됨)
 *
 *     ※ 폴더가 없으면 Gen NX가 에러 다이얼로그를 띄우고 MAPI 호출이 타임아웃됩니다 —
 *       실제 호출로 확인함(2026-08-31, 아래 "Save Folder Must Already Exist" 참고).
 *     ※ %USERPROFILE% 같은 환경변수는 MAPI 서버(Gen NX 프로세스)가 인식하지 못합니다.
 *     ※ /mapikey/verify 의 j.user(로그인 이메일) 앞부분을 Windows 사용자명으로 가정해
 *       C:/Users/{username}/... 을 자동 구성하는 방식은 사용하지 않습니다 — 로그인 이메일
 *       계정과 실제 PC의 Windows 계정명은 서로 다를 수 있기 때문입니다(예: 회사 이메일
 *       "kim@midasit.com" 이지만 Windows 계정은 "user01"). j.user는 연결 확인 용도로만
 *       쓰고, 저장 경로는 호출자가 실제 존재하는 폴더를 saveDir로 직접 넘겨주세요.
 *
 * EN: Determine save path.
 *     1st : the folder passed explicitly as saveDir (recommended — always correct)
 *     2nd : C:/Temp  (fixed fallback when saveDir is not given — this folder must also
 *           already exist; it is NOT auto-created)
 *
 *     ※ If the folder is missing, Gen NX shows an error dialog and the MAPI call times
 *       out — verified with a live call (2026-08-31, see "Save Folder Must Already Exist" below).
 *     ※ Environment variables like %USERPROFILE% are NOT resolved by the MAPI server.
 *     ※ We deliberately do NOT guess C:/Users/{username}/... from the local part of
 *       j.user (the login email) returned by /mapikey/verify — the login email account
 *       and the actual Windows account on the PC can differ (e.g. email "kim@midasit.com"
 *       but Windows account "user01"). Use j.user only to confirm the connection; pass a
 *       real, existing folder as saveDir instead.
 */
async function autoSavePath(base, key, saveDir) {
  const dir = (saveDir && saveDir.trim()) ? saveDir.trim().replace(/[\\/]+$/, '') : 'C:/Temp';
  return `${dir}/gen_rc_temp_${Date.now()}.mgbx`;
}

/**
 * KO: 단위 설정 → 모델 생성 → 저장 → 해석 전체 흐름
 *     setUnit 은 모델 생성(노드 추가) 전에 반드시 호출해야 합니다.
 *     saveDir: 실제 존재하는 저장 폴더를 호출자가 넘겨줍니다(권장). 생략 시 C:/Temp 사용.
 * EN: Set unit → build model → save → analyze — full flow.
 *     setUnit MUST be called before creating any model entities (nodes/elements).
 *     saveDir: caller-provided folder that actually exists (recommended). Falls back to C:/Temp if omitted.
 */
async function runAnalysis(base, key, saveDir) {
  const headers = { 'MAPI-Key': key, 'Content-Type': 'application/json' };
  const api = (method, path, body) =>
    fetch(`${base}${path}`, { method, headers, body: body ? JSON.stringify(body) : undefined });

  // ① 단위계 선제 설정 (KO: 노드 추가 전 필수 / EN: must call before PUT /db/node)
  await api('PUT', '/db/unit', { Assign: { 1: { FORCE: 'N', DIST: 'MM' } } });

  // ② ... 모델 생성 (nodes, elements, loads ...) ...

  // ③ 저장 — 반드시 /doc/anal 보다 먼저 (EN: must precede /doc/anal)
  const savePath = await autoSavePath(base, key, saveDir);
  await api('POST', '/doc/saveas', { Argument: savePath });

  // ④ 해석 (EN: run analysis)
  await api('POST', '/doc/anal', {});

  return savePath;
}
